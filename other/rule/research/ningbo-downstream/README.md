这里的年份分别标明“采集”“会议／卷年”“出版”“条款修订”“本次访问”。最早找到的规则见证，只能证明该版本在当时已经存在，不能直接当成发明年。直接描述改法的原典、同一组织明示的版本修订，可以支持具体分化；同牌数、同番种、相邻地区或后出的历史解释，不能单独证明父子关系。
