## О проекте

open_mahjong_unity — платформа для маджонга на базе Unity и Python/FastAPI. Это бесплатный проект с открытым исходным кодом под лицензией MIT, поддерживающий совместную игру на ПК, Android и в браузере. Цель проекта — поддержать все существующие в мире правила маджонга и предоставить игрокам возможность настраивать их. Присоединяйтесь к группе QQ, чтобы обсуждать проект, помогать в разработке и участвовать в тестировании.

## 3. Технологии

### Игровой клиент (open_mahjong_unity)

- **Движок**: Unity 6.4 (6000.4.7f1)
- **Язык**: C#
- **Сеть**: WebSocket (Nativewebsocket)
- **Платформы**: PC/Web/Android/iOS

### Игровые серверы (open_mahjong_server, open_mahjong_chat_server)

- **Фреймворк**: FastAPI
- **Языки**: Python 3.12, Golang
- **Сеть**: WebSocket, HTTP
- **База данных**: PostgreSQL 18
- **Развёртывание**: supervisor или любой удобный вам менеджер процессов

### Веб-платформа (open_mahjong_web)

- **Фронтенд**: Vue3
- **Бэкенд**: Node.js
- **База данных**: PostgreSQL 18
