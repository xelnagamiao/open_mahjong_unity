建议：保留一个“麻雀计算器”入口

用户只管录入和修改手牌，结果区根据牌数与牌形自动呈现相应内容。

最顶部保留牌面简写说明，其下选择规则；手牌、副露、和牌张、已见牌及条件始终属于同一份状态。规则切换会重新计算，并恢复对应规则的和牌牌型预设。原来两页之间的“带着手牌跳转”变成当前页内的一步操作。

交互与状态保留

输入、摸牌、切牌

简写提交与牌面点选进入同一状态。14 张简写默认末张为和牌张，也支持 手牌 + 和牌张；“指定和牌张”只改变末张归属，不改变整副牌。切牌加入推演牌河，后续进张立即扣除。手动重新编辑整副牌视为开始新的推演。

等待牌与算分接起来

13 张结果直接展示点和与自摸两种得分；点击其中一格即把这张牌和对应条件带入 14 张结果。无役或不足起和也如实列出，可进入检查。和牌后“退回听牌”移除末张，保留已见牌与此前推演牌河。

规则、牌型、条件

切换规则保留手牌和副露，重置和牌牌型开关。未提交的简写先解析，错误时保持当前规则。手动开关重算两类结果。两种七对互斥；非门清时清除立直、一发和里宝牌；和牌方式与抢杠、杠上条件联动。

分享与撤销

链接携带规则、牌、末张、副露、已见牌、牌河、场风、自风、和牌条件及牌型选项。打开后本地重算，不上传手牌。分享导入后的编辑会更新地址片段；同页换链接与刷新均可恢复相应状态。撤销按完整状态恢复，避免只有牌恢复而条件没恢复。

一条可以直接试的流程

  1. 打开示例，选择“一向听”，点击任意有效进张，再选最低向听的舍牌，进入待牌比较。
  2. 输入 123456789m23p55s，比较一饼与四饼的点和、自摸；点击一饼自摸，国标结果为 23 番。
  3. 撤销回听牌，改选四饼；重做分支随新选择更新。切换青雀、日麻，手牌仍在，得分与牌型设置自动变化。
  4. 展开已见牌，输入 111p4444p 并应用，同一听牌只剩一饼 1 张。超过四张会被拒绝。
  5. 选择“多种拆解”查看不同分组，或切到日麻选择“日麻无役”，再开启立直观察结果变化。
  6. 分享链接，在另一标签页打开；继续推演、刷新、撤销，检查牌与条件是否一致。

规则覆盖与扩展边界

规则切换后的牌型预设得分与上下文
国标一般型、国标七对、十三幺、全不靠、组合龙。番种、番数、全部拆解；8 番起和检查，花牌不用于补足起和番。

此次可操作示例完整覆盖刚整合的这三种常规牌组规则。虹雀²采用不同牌组与计算入口，另列正式接入适配：规则配置应提供牌集、张数上限、副露规则、选项、分析器、得分渲染器和输入序列化，复用同一外层流程。虹雀²按钮进入原有计算器，原有虹雀²牌理入口同样保留。

后续引入虹雀²前，应验证它的每种输入状态、特殊牌集剩余张数和分享格式，再开放对应规则入口；不能把常规 34 种牌与固定 14 张约束直接套用。

本地实现与验证

合并回归：88 项控制器与引擎测试；17 组浏览器场景、175 项断言。覆盖四种视口、副露编码双向同步、旧链接与分享兼容；另有 30 项 SEO 测试通过。计算 API 请求 0 次，页面异常 0 项。
  • 复用现有真实本地引擎、牌面、得分、拆解、副露与条件组件；结果由浏览器 Worker 计算，Worker 不可用时回退到同一浏览器内引擎。
  • 正式页面从旧计算器会话迁移手牌与独立副露，不修改原始存储；示例继续使用独立存储。测试覆盖大小写、编码删除、完整状态恢复和异常输入。
  • 浏览器自动化记录 Worker 与网络请求，验证不调用 Node / Python 计算接口；页面加载后断开网络，三种规则仍能计算向听和得分。
  • 桌面 Chromium / Edge 自动化覆盖 360、390、768、1440 px 布局。手机尺寸是浏览器视口模拟，不冒充真实 iOS / Android 设备测试。

已有规则引擎的单元测试和离线固定样例一并回归；此次验证针对整合页面及现有引擎，不宣称重新穷举全部麻将手牌，也不代表已测试下列外站的计算正确性。

这些例子共同支持的取舍

统一状态和自动结果分派主要借鉴 livewing、Mahjong Calculators；待牌与分值并列主要借鉴雀角；连续切摸和已见牌主要借鉴 Tenpai.gg 与效率训练工具；条件分层、末张和副露录入借鉴 RiichiCam、XDean 等。没有一个外站决定本站配色或布局，也没有把外站计算接口接入页面。

正式合并结果

  1. 共享页面组件：正式页与示例复用同一页面和会话控制器；三规则通过路径或选择器确定初始预设。简写内同步 (s13)(K23)，槽位与文本互相更新。
  2. 兼容旧链接：现有 /paili、/paili/qingque、/paili/riichi 与对应 /calc/… 路径进入同一界面，旧会话自动迁移；查询参数和分享片段保留，现有牌谱链接无需修改。
  3. 导航与 SEO：导航保留“麻雀计算器”；旧牌理路径跳转到对应 /calc/ 路径并保留查询参数及分享片段。canonical 指向计算器，站点地图不重复列出旧入口；原 SEO 翻译继续保留。
