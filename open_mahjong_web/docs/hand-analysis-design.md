# 国标计算器与国标牌理互通设计

日期：2026-09-23。本文替代上一版方案，以保留现有界面、美术风格及部件名称为前提。

## 方案选择

保留“国标计算器”和“国标牌理”两个页面，共享输入状态与计算逻辑。每页在原有结果区输出当前手牌所需的结果，并提供进入另一页的按钮。

只增加跳转会继续留下 13 张不能算、14 张不能显示和牌的断点；把所有输入控件合成新页面又会改变用户熟悉的操作。两页互通、结果组件共用可以同时解决这两个问题。

| 输入 | 国标计算器 | 国标牌理 |
| --- | --- | --- |
| 等效 13 张，听牌 | 原结果区显示听牌与进张 | 保留原来的听牌与进张 |
| 等效 13 张，未听牌 | 原结果区显示向听与进张 | 保留原来的向听与进张 |
| 等效 14 张，未和牌 | 原结果区显示切牌表 | 保留原来的切牌表 |
| 等效 14 张，和牌结构成立 | 显示番种构成；“查看全部拆解”展开拆解 | 显示番种构成与全部拆解 |
| 结构成立但不足 8 番 | 显示实际番数及不能和牌的原因 | 同样显示，不混同于无和牌结构 |
| 张数不足、同牌超过四张、未完成副露 | 明确提示；保留输入，不显示旧结果 | 同左 |

副露每组按三张计算等效张数；明杠、暗杠按四张实物牌检查余量并显示。

## 保留的界面

- `/calc/chinese` 继续使用 `ChineseMahjong.vue`，保持原有青色背景、白色卡片、手牌与右侧“和牌”、副露、花牌、和牌方式、选牌区及操作区。
- `/paili` 继续使用 `Paili.vue`，保持原有紫色背景、特殊牌型开关、手牌、副露、选牌区及切牌表。
- `CalculatorSwitcher`、`PailiSwitcher`、`TileChip`、`TileMiniGlyph`、`TilePalette`、`TileFaceStyleSwitch`、`FuluSlots` 均沿用。“小助手”“立体”“番种构成”“全部拆解”“切”“向听”“进张”“摸”等名称保持原样。
- 没有新增主题、字体、插画、图标、牌面素材或产品名称。上一版新页面与牌面组件已撤下；不再存在需要切换的“原版工具”入口。
- 两页仅补充必要的结果内容和“国标牌理”/“国标计算器”互通按钮。窄屏按钮允许换行；十三幺等长拆解在原卡片内横向滚动。

## 交互

1. 继续使用牌面简写、点击牌面及原有副露槽输入。计算器保留右侧和牌张；牌理也接受“手牌 + 和牌张”的同一简写。
2. 计算器“计算得分”和“解析”自动识别 13/14 张。牌理“计算牌理”和“解析”自动识别是否存在和牌拆解。
3. 听牌进张可点击“摸”入手牌，直接继续计算。切牌表的“切”可点击进入 13 张状态；同一行“摸”的牌可直接完成切牌后摸牌。按钮有对应牌名的键盘可访问名称，不更换牌面。
4. 两页使用同一输入状态。转入另一页时保留手牌、副露类型、和牌张、点和/自摸、场风、自风、花牌及特殊条件。13 张不会被自动补成 14 张。
5. 牌理显示的番数使用当前计算器条件，并在结果下方列出“点和/自摸 · 场风 · 自风 · 花牌”等实际条件；需要修改时通过“国标计算器”进入原有控件。
6. 特殊牌型开关控制牌理的向听、进张与切牌计算；国标算番仍按国标规则识别合法和牌结构。国标七对与日麻七对保持原来的互斥操作。
7. 清空同步清除两页共用手牌、局况与结果。当前标签页通过 sessionStorage 保存输入；刷新后恢复。浏览器禁止存储时仍可计算。

## 计算与数据边界

`useGuobiaoCalculator.js` 管理共用输入、原有副露控件、存储和计算请求；`handAnalysis.ts` 调用项目已有国标引擎与 `pailiCalculator.ts`。两页共用 `PailiResult.vue`、`GuobiaoScoreResult.vue`、`GuobiaoDecompositions.vue`，这些结果组件的标记和样式提取自原页面。

- 手牌、副露、和牌条件、牌理选项或文字输入发生变化时立即作废旧结果；终止旧 Worker，拒绝迟到结果。
- 输入校验通过后才更新手牌；错误不吞掉输入。未确认的副露类型会阻止计算和转入另一页。
- 新增副露若超过等效 14 张或四张同牌，直接提示；不静默截断手牌。
- 进张余量扣除手牌、副露以及本次点击切出的牌。切出的牌不能被当作剩余牌摸回来；手动换一副牌后重新开始计数。没有推测其他玩家未输入的已见牌。
- 结构成立和达到起和条件分别判断。花牌显示在总番数中，不补足 8 番起和门槛。
- 点和/自摸与抢杠和、杠上开花、海底捞月、妙手回春保持相容；选择条件时使用其对应的和牌方式。
- 计算在 Web Worker 内执行；Worker 无法创建或运行失败时使用同一引擎回退。超时给出提示，输入仍保留。
