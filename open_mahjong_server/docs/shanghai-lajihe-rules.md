# 上海垃圾和

子规则标识为 `shanghai/lajihe`，建房入口为「上海麻将 → 上海垃圾和」。原始规则保存在 Web 的 `client/public/rulebooks/shanghai-lajihe.docx`，规则书页面提供下载。

建房描述：上海垃圾和是上海本地的一款特色麻将规则，使用144张麻将牌，允许垃圾和的同时对点和做了花数上的限制，并有七对子、自摸加底等特色内容，节奏适中。

## 已确认的解释

2026-10-09 用户确认：七对子允许四张相同牌算作两对；大吊车包含暗杠；起手有花、先鸣牌再补花时，补完花允许杠牌和自摸。

## 行牌和资格

- 144 张：数牌和风箭牌各四张，加春夏秋冬梅兰竹菊八花。风箭牌参与组牌；暗杠四张公开，仍按暗杠计花。
- 普通和型为四面子一将；另外允许七对子和不限结构的全风向。七对子不自动复合清一色、混一色或碰碰和；另有合法普通拆分时择高计分。
- 上家可以吃，三家可以碰、直杠；可以暗杠和加杠，均从牌尾补牌。只有加杠可以抢杠。
- 普通吃碰后必须打牌，不能立即杠。起手补花例外按上述确认执行。
- 禁止同巡食替，包括 23 吃 1 后打 1 或 4。第四副吃牌解除本次禁切；第四副碰牌不解除。
- 自己打出当前听张，或有资格点和/抢杠而放弃，进入过和：再次实际摸牌之前所有和牌被禁止，吃碰不解除。放弃碰牌后同张不能再碰，摸牌解除。
- 庄家先补起手花；闲家鸣牌后补起手花。闲家轮到摸牌时，先补起手花，再重新判断刚才上家的弃牌，然后才摸头牌。
- 垃圾和点和至少需要两花，含手中的字刻和已成立的杠花；自摸与抢杠不受该门槛限制。大吊车、杠头开花等附加分不能代替点和花数要求。
- 每副牌不留王牌；末张仍可和牌，没有补牌则不能杠。首庄随机；单家和牌由和者坐庄，多家和牌由放铳/被抢杠者坐庄，流局庄家不变。局数照常推进，无荒番欠局、承包或敲牌要求。

## 计分

基础番择高，不相加：

| 基础番 | 基础分 | 番数 |
| --- | ---: | ---: |
| 垃圾和 | 5 | 0 |
| 碰碰和、混一色、七对子 | 20 | 0 |
| 清一色、混碰 | 25 | 0 |
| 清碰、全风向 | 20 | 1 |
| 全风向碰碰和 | 20 | 2 |

自摸增加 5 分（垃圾和）或 10 分（其他）；抢杠按相同金额增加，视为自摸但不重复加自摸分。大吊车加 5 分，杠或花补牌和牌加 5 分。

建房开关「自摸再加一底」默认关闭，对应 `detailed_config.self_draw_extra_base`。开启后在自摸加分上再加 5 分，即垃圾和加 10 分、其他牌型加 15 分；这部分参加番数翻倍，抢杠同样适用，普通点和与八花奖励不变。缺少该字段的旧房间、旧牌谱按关闭处理。此开关采用原始文档关于自摸 +10／+15 的可选口径，2026-10-14 用户要求将其提供为默认关闭的选项。

实际花数：每张花牌一花；每副字刻一花；数牌明杠一花、暗杠两花；字牌明杠两花、暗杠三花。风和箭按相同标准。

| 实际花数 | 花分 |
| --- | ---: |
| 0–2 | 0 |
| 3–4 | 5 |
| 5–6 | 10 |
| 7 | 15 |
| 8 | 20 |
| 9 及以上 | 每多一花加 5 |

和牌点数 =（基础分 + 附加分 + 花分）× 2^番数。点和由放铳者支付一份，自摸三家各支付一份，抢杠由杠者支付三份。多人和牌分别计算。

收齐八张真实花牌立即向三家各收 30 分，再选择继续或流局；无剩余补牌时仍先收分。奖励只记独立收分，不记和牌次数，不翻开手牌。继续后的和牌结算另算。

## 提示、消息和牌谱

2026-10-10 用户明确要求：听牌分值提示仅显示「x番x分」，例如「0番5分」「1番40分」，不添加和牌方式或条件说明。此前说明中的双分值文案是实现时自行添加的内容，并非原始规则文档的显示要求，现已纠正。

番数与分数取同一个择高结果。可点和时显示其分值，仅能自摸时显示自摸分值，资格沿用提示颜色区分；过和或未满足和牌条件显示「0番0分」并保留禁和颜色。不把尚未发生的抢杠、杠头开花加入普通预估。

`game_info`、`ask_hand_action_info`、`do_action_info` 使用可选字段 `lajihe_passed_win` 恢复本人资格，其他座位收到自己的值。八花选择使用 `lajihe_flower_end` / `lajihe_flower_continue`；超时和机器人默认继续。

牌谱奖励 tick 为 `["lajihe_eight_flowers", seat, 30, ["八花齐"], deltas]`，`deltas` 按本局座位排列。过和使用 `["state", "lajihe_passed_win", seat, "T"|"F"]`。顺序播放、跳转、分数累计和结算历史均处理这两个事件；抢杠回放恢复原碰牌。
