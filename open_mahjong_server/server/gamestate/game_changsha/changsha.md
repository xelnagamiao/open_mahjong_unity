# 长沙麻将经典双鸟规则

- 使用万、筒、条 1-9，共 108 张牌。
- 允许吃上家牌，允许碰、杠和抢杠胡。
- 小胡要求 4 组面子和 258 将；经典基础分保持小胡 1/2、大胡 6/7。
- 创建房间可开启卡摸，开启后标准小胡只能自摸，所有现有大胡仍可接炮；默认关闭。
- 两种计分模式均可选择不封顶、大胡数量封顶或最终分值封顶，可选常用档位或在创建房间时自定义，开局后固定。大胡数量先封顶再算鸟，分值在鸟之后封顶。
- 封顶按每个付款方分别计算；同一开杠批次中同一付款方给同一赢家的多张胡牌累计后封顶，不同赢家分别封顶。起手胡不受任何封顶限制。
- 开杠张数只可选2或4。每次明杠、暗杠、加杠重新掷两个骰子，从牌墙尾部第1墩向前数，优先取骰子和数对应的墩，开4张还取下一墩。
- 起始墩不存在时改按较小骰子的点数定位；小点数仍越界则开出0张。定位到的墩存在时拿实际牌张，后续墩不足不再回退，半墩也算一墩。牌墙最后一张海底牌始终跳过。
- 开出0张仍视为杠成立且锁手，不补牌也不再出牌，直接下家继续摸打；仅剩海底时进入下家的海底流程。补张仍按原流程补一张，不掷骰子、不锁手。
- 大胡支持碰碰胡、将将胡、清一色、全求人、七小对、豪华七小对，以及天胡、地胡、海底、杠上开花、杠上炮、抢杠胡等情境牌型。
- 扎鸟张数可选 0、1、2、4，可选择从本局开始庄座位 0 或胡牌玩家起算。
- 海底牌先盖放在桌面中央。玩家选择后翻开并进入该玩家牌河；该玩家能胡时按海底自摸结算，否则视为打出海底牌，只允许其他玩家荣和或跳过。
- 开杠补牌先逐张判断本家自摸；多张可胡时手牌牌型只计算一次，并按可胡张数累计杠上开花。本家可选择和牌或跳过，但不能修改原手牌。
- 本家不能和或主动跳过时，再收集每张补牌上的全部他家荣和。同一张允许一炮多响，同一赢家胡不同补牌时分别计分，整批共用一次扎鸟；不分庄闲计分时以开杠者作为本批鸟起点。
- 本家跳过杠上开花后，整批合并基础分作为过手阈值；紧接的强制摸切不清除该限制，直到该玩家下一次实际摸牌，自摸始终不受过手限制。
- 无人和牌后才判断本家暗杠；本家可选择任一成立的暗杠，其他补牌先摸切且不再开放他家响应。
- 本家不暗杠时，其他玩家鸣牌按杠、碰、吃和座次确定唯一动作。玩家开杠后锁手至本局结束，后续普通摸牌只能自摸、暗杠或摸切刚摸到的牌。
- 吃、碰、明杠统一使用 `cut_from_player` 和 `cut_tile` 标识被认领的弃牌来源和牌值。
- 起手胡支持四喜、板板胡、缺一色、六六顺和三同，具体类型可以在创建房间时开关。
- 四喜只亮出命中的四张牌，六六顺只亮出对应两个刻子的六张牌，三同只亮出三门同点数对子共六张牌。
- 同时命中多个固定子集牌型时合并所需牌张；板板胡或缺一色无法用固定子集完整表达，因此仍亮出整手牌。

## 换六张固定玩法

长沙房间的子规则下拉框选择"长沙麻将(换六张)"后使用 `changsha/exchange_six`，规则版本为2，依六页新版规则及用户确认执行。另一项"长沙麻将(经典双鸟)"仍为默认。换六张采用以下完整玩法，旧长沙的起手胡、开杠张数、鸟数和底分选项隐藏。切回经典双鸟后恢复原设置和值。

### 开局、胡牌资格与声明

- 使用108张数牌，庄家14张、闲家13张。先换牌，再处理四喜，之后由玩家选择报听、明牌，最后庄家选择天胡或出牌。
- 建房可设置选六张时间，10到60秒、默认30秒。每轮独立计时，不扣正常出牌的局时，也不另加步时；重连继续剩余时间，超时由服务器自动选合法六张。
- 四家先选好并提交六张，选牌时不公开换牌骰子和方向。收齐后播放两颗骰子动画，按最终点数交换；动画完成后显示换后的手牌。第二轮预留流程同样先选牌后掷骰。
- 每一小局重新掷开局抓牌骰子，独立于换牌骰子，按本局庄家起算：点数和5/9指定庄家禁终局小胡，2/6/10为下家，3/7/11为对家，4/8/12为上家。连庄也重新确定，不沿用上一局结果。该家接炮和自摸都不能以纯小胡终局；合法小胡升为大胡后可胡，仍可听牌、选择海底和收四喜。
- 每家交出自己的六张，最多两种花色。两骰点数和为奇数时拿对家牌，2/6/10拿下家牌，4/8/12拿上家牌。四家收齐后同时交换。交出三门的合法六张牌仍交换，但该玩家本局相公，不能胡；数量或牌归属错误的请求直接拒绝。
- 预留最多两轮换牌：第二轮重新用当前手牌选六张、收齐后统一交换，第一轮相公继续保留，最终换牌结束才进入四喜及声明。服务端second_exchange_dice条件入口目前返回None，正常开局只换一轮；触发条件及第二轮骰子/方向办法待确认，客户端不能自行要求第二轮，也无建房次数开关。入口将来明确提供第二轮骰子后复用现有方向映射；不能静默沿用或重掷第一轮骰子。
- 普通小胡为四组面子加二五八将。仅有天胡、地胡、海底、杠上花、杠上炮、抢杠等胡牌方式，仍须二五八将。报听或符合手牌大胡条件才可放宽；明牌本身不能使不合法手牌成立。
- 手牌大胡包括清一色、碰碰胡、全求人、将将胡、七小对、豪华七小对、十三将、全幺九。全求人须四组面子全部明副露。豪华七对计2/3/4大，替代普通七对的1大。全幺九计2大，不要求普通面子结构。
- 十三将无副露，包含一万/九万/一筒/九筒/一条/九条各一张，再加二五八中的七种不同牌和任意一张二五八。带将对计1大；八张将牌都不同、无将对计2大。
- 天胡本身计1大。明牌、报听各计1大，均由玩家单独选择。因此天胡加明牌加报听为3大32分，有清一色再加1大为64分。
- 地胡按每位闲家独立判断：本家第一次实际取牌自摸，或此前接炮均算地胡。庄家后续摸牌不取消其他闲家资格。本家首摸出牌后、第二次取牌及续杠批次不再算首摸地胡。普通摸牌、单张补张、海底和公开杠牌批次均更新实际取牌次数；闷杠隐藏一张与该次公开四张作为同次取牌操作。
- 报听后只可保持听牌杠摇；已有杠摇锁手时，也可保持原听牌补张，其他情况不能改变原手。报听者过胡后，同番或更低不能再接，摸切也不解除，升番可接，自摸不受此限。明牌后手牌、摸牌及副露公开。明牌者放弃同牌型的胡牌后，同牌型同番或更低不能再接；升番可以接，实际听牌集合改变后恢复。

### 四喜、开杠与闷杠

- 起手及中途仅四喜即时收分，每组四张分别按小胡自摸收分，分别掷两颗骰子鸟；同种牌本局不重复收分。牌局继续，不改变庄家，也不叠加报听、明牌权重。
- 每小局选六张前先播放禁小胡双骰动画，展示本局不能胡普通小胡的玩家，四喜仍可收分。展示结束后才开始选牌计时；四家选定后的换牌方向骰子另行展示。
- 海底牌也是实际摸入手牌，凑齐第四张时先提供中途四喜，再处理海底胡牌或弃牌。
- 杠摇锁定原手及各张预有听牌对应的手牌大胡组合。后续不能改原手做出新的手牌大胡。锁牌后原暗刻摸到第四张，仍可收中途四喜；之后只可保听杠摇、保听补张一张或打掉新摸的第四张，补张后继续锁手。公开杠牌凑成第四张的续杠窗口也同时提供保听杠摇与单张补张；原明刻可补杠，原暗刻可暗杠。
- 正式开杠固定开四张，普通补张只取一张。掷两骰后从墙尾按点数和定位，取连续两墩；起始墩不存在时才退到较小骰子。恰好定位最后一墩只取该墩，半墩单独处理。若选中牌墩将取空牌墙，留下最后所取墩的下层为海底；其余情况不固定排除墙尾牌。
- 开出的牌作为一批公开牌，不进入原手。先判断本家整批自摸；本家选择胡则优先结算，才轮到其他三家逐张、多响判断。所有结果共用一次两只鸟。
- 本家不能胡或选择过后，公开杠牌额外停留1.2秒再入牌河。停留不扣玩家操作时间，他家响应计时在停留结束后才开始。
- 没人胡时提供全部合法续暗杠目标。选择续杠只使用对应的一张公开牌，其他公开牌进入牌河且不另开响应窗，再进行下一批开杠；不续杠时按杠摇、补张或碰、吃及距离优先只执行一次副露。同级下家优先于对家、上家。直杠可选择正式杠摇或单张补张；未听牌者不能杠摇，但可以补张。
- 闷杠在摸牌前选择并向三家声明。先取一张但隐藏，再公开四张杠牌，之后本家才看先取的那一张；未明牌者该张只本人可见，明牌者最后也公开。本家整批胡优先，闷杠胡在对应杠上花或杠上炮基础上额外加1大。
- 开局选择明牌后立即公开手牌，不等待其他玩家完成声明。报听、明牌及对应牌谱记录均在服务器确认该玩家动作时生效；其他玩家仍可继续选择，重连恢复已生效的声明。
- 明牌闷杠增加本家私下查看窗口，公开手牌此时仍不包含新摸牌。本家选择"查看后继续"或服务器超时后，才将该牌公开；此窗口重连使用相同裁剪，不提前泄露。
- 闷杠选项只能依据已知手牌及可能摸牌出现，不依据尚未看的实际牌值。实际摸牌没让本家听牌时杠仍成立，本家不能胡本批，四张继续给其他家判断并走强制弃牌。
- 支持补张前闷杠：有多个杠目标，先做一个单张补张，在取补牌前用另一个目标声明闷杠；隐藏的一张来自前一个补张，再公开四张。
- 抢大明杠和抢小明杠的正式开杠均加1大，由准备开杠的人付款；单张补张的抢补杠不升番。仅十三将允许抢暗杠。抢胡成立后取消该杠及补牌。
- 普通漏胡限制持续到本人完成出牌，摸牌不解除，升番可接，自摸不受漏胡限制。本人强制打出公开杠牌也算出牌；仅将一张公开牌用于续杠而没有弃牌时不提前解除。报听永久过胡和明牌同型限制独立保存。海底仅听牌者可选择，不能胡或选择过则打出该海底牌，其他家只可胡或过。
- 明牌者放过可胡牌后，本人手牌上方显示同型过胡提示：听牌不变时，同牌型须升番才能接炮；改变听牌解除该同型限制，自摸不受影响。提示随重连恢复，其他玩家、观战者和回放不显示。

### 计分、鸟与下一庄

- 小胡底分2；1大8；n大为 `8 * 2^(n-1)`。自摸由其他三家各付，接炮由放炮者付。
- 同一赢家的同一完整手牌大胡组合合成一组，手牌大胡只计一次，可胡的每张开杠牌各加1个对应杠胡权重。不同组合分别算分再相加，开花、开炮使用相同算法。
- 开杠接炮过胡先按完整分组计算：明牌同型限制比较每组鸟前底分，普通/报听限制比较其余合法组的鸟前总额。赢家声明及闷杠附加计入阈值，付款者声明与鸟不计入。三张同型过胡后两张仍不可接、四张升番可接；混合组合48分过胡后32分仍不可接、64分可接。
- 三张清一色: 清一色1大加杠胡3大，共4大64。清一色一张、清碰一张: 2大16加3大32，共48。两张清一色、一张清碰: 3大32加3大32，共64。以上均为鸟前每笔底分。
- 赢家报听、明牌各加1大。付款者自己的报听、明牌只增加其付款: 乙普通小胡自摸、甲报听时为甲8、另两家各2；甲同时报听明牌时为甲16、另两家各2。
- 一次正常胡或一次开杠整批只翻一次两只鸟。单赢家以赢家起算，多赢家以放炮者/开杠者起算；1/5/9为起点，2/6下家，3/7对家，4/8上家。
- 每笔付款的鸟落到赢家或该付款者时命中，每中一鸟乘2，两只都中乘4。鸟前48分、两只都中为192分。剩一张鸟牌重复计算两次；海底胡使用海底牌重复两次。四喜用两颗骰子点数分别按同样座位及翻倍规则计算。
- 下一庄按不同赢家人数: 只有一位赢家，由赢家坐庄；两位或三位赢家，由放炮者坐庄，开杠多响则开杠者坐庄。同一赢家胡多张或多个组合仍只算一位赢家。

### 协议与回放

模式快照为长沙专用 `gamestate/changsha/exchange_six_state`。公共字段仅公开骰子、已提交座位、声明、公开牌和计分；本家六张选择、手牌和提示放在私有字段。隐藏摸牌在公开四张前不进入任何玩家可见的手牌字段。重连、AI与超时使用相同服务器阶段和动作验证。

exchange_round与completed_exchange_rounds分别记录当前及完成轮次，每轮新action_tick并清空上一轮提交。changsha_exchange_start记录选牌窗口，骰子为空、方向为0；四家提交后changsha_exchange_roll记录骰子和方向，随后changsha_exchange_six记录本轮交换及轮次。回放按当前手牌依次恢复，两轮不能折叠成一次交换；兼容旧start中已带骰子的记录。进入四喜前关闭换牌入口，拒绝重叠或第三轮。

牌谱标题记录规则版本，局内记录抓牌骰子/禁手座位、原子交换、声明、即时四喜、实际取牌次数、锁牌型、隐藏取牌/查看、按骰子抽墩、公开批次弃牌、续杠收回、海底取牌/释放及整批结算。公开四张不能按普通摸切从原手扣牌；四喜已即时收分，终局回放只补剩余差额。重连保留同一抓牌骰子和禁手标记，客户端与回放提示显示禁小胡而不抹掉合法听牌结构。

实战终局score_changes包含完整局差（含四喜），player_to_score为权威结算后绝对分；客户端历史记完整局差，账面分数写绝对值，避免重复四喜。胡牌说明包含完整牌型组及逐付款底分、鸟倍数和实付；多人回放逐家使用权威代表手牌倒牌，但只播放一个共享结算面板。
