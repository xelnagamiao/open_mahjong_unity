# 虹雀启发式 Bot 实验报告

作者: [baisebaoma](https://github.com/baisebaoma)

本报告记录虹雀模式高性能罗伯特（`user_id=3`）启发式实现的**实验历程、取舍依据、
验证数据与后续方向**，供后续维护者理解设计并继续推进。当前交付版本见
`heuristic_bot.py`（`HongqueGameState.py` 中 `user_id=3` 的出牌/鸣牌入口）。

给主仓库提交的 Pull Request 是精简后的，完全不提交任何旧版本、新实验版本，保持代码干净。要不然把 v1 v2 v3 v4 v5 v6 v7 都推上来太变态了。所有旧版本新版本的代码、完整的实验报告，请访问 [Fork 中的实验分支](https://github.com/baisebaoma/open_mahjong_unity/tree/hongque-heuristic-experiments)

## 1. 玩法背景（决定算法形态的前提）

- **126 张牌**：7 种纯色 ×1-9 + 7 种半色（相邻两色） ×1-9。
- **单副本牌库**：每种牌全局只有一张 → 对手弃过的牌（现物）对该对手**必然安全**，
  这是防守设计的基础。
- 每副牌约 **9 次摸牌**；实测**荣和占 76% / 自摸占 24%**——防守有价值。
- **和牌 = 12 张全部属于 ≥3 张的合法组，没有雀头**；不存在单骑听。
- 组牌是竞速：**先和牌的人结束本小局**，约 9 次摸牌内要组出 4 组。

## 2. 当前交付版设计（heuristic_bot.py）

三层结构，自底向上：

1. **听牌计分**：对每个活听口用 `best_win_result` 打分，偏好多番听牌
   （牌效 bot 完全无视计分，只和便宜的小番）。
2. **做牌方向**：未听时软性风格分（清一色/双色/三色、清一数/二数/三数、全带幺、
   金龙/二金）作为结构距离之上的平局决胜，永不硬性牺牲效率。
3. **威胁门控折叠**：单副本 → 对手已弃的牌是现物安全；对手副露揭示其做牌方向；
   仅当巡目靠后且对手河牌变长时才离开纯进攻——近手保持进攻、仅在等价时偏好安全牌，
   远手在小的距离预算内折向最安全弃牌。阈值 `_DEFENSE_THREAT=0.5`、
   `_STRONG_DEFENSE_THREAT=0.75`。

## 3. 实验历程与取舍

| 版本 | 内容 | 结果 |
|------|------|------|
| v1 牌效 | 纯结构距离（`efficiency_bot.py`，`user_id=2`） | 基准；均番 ≈1.84 |
| v2 | v1 + 番种计分偏好（听牌计分 + 做牌方向） | 对牌效早期即显著领先（均顺 2.05 量级） |
| **v3（= 当前交付）** | v2 + 威胁门控折叠 | 对牌效跨块稳健显著：**均顺 2.28 [2.06, 2.50]，p=0.023** |
| v4（未上线） | v3 + 得分预期×威胁衰减 + 海底强制绝安 | 对牌效不劣于 v3，但 vs v3 合并约 500 场仅方向占优、未达显著线 |
| v5/v7（已否决） | 防守加码：鸣牌抑制（D3）、副露加权威胁（D1） | 1v3 自战中**负收益**（v5 均顺 2.748 / v7 2.550） |
| v6（未上线） | 听牌安全平局取舍（E3） | **唯一不亏损的微调**，800 场合并 ≈2.47，但 CI 未达显著线 |

**核心教训**：虹雀² 是短手牌竞速游戏——防守换来的"少放铳"抵不过"自己慢和牌把分喂给
三个对手"。v3 的威胁门控已接近这个维度上的局部最优；后续方向应优先**进攻侧**
（见 §6）。所有未上线版本均保留在实验分支，未随本 PR 提交。

## 4. 验证数据（heuristic_bot vs 牌效）

### 4.1 强度（统计显著，跨块反复确认）

- 平均顺位 **2.28**，95% CI **[2.0632, 2.4968]**（上界 < 2.5），单侧 p=0.0234。
- 净分 **+4.59/大场**，95% CI **(0.59, 8.58)**（下界 > 0，p=0.012）≈ 领先对手平均分约 15%
  （折合 +0.29/小局）。
- 口径：1v3 自战、座位轮换、确定性种子；200 场 = 3200 小局。

### 4.2 响应时间（不慢于牌效，玩家无感知）

| 决策 | 牌效 mean / p95 | heuristic_bot mean / p95 | 比值 |
|------|---------------|--------------------------|------|
| turn | 5.66 / 13.3 ms | 6.24 / 14.5 ms | 1.10× |
| claim | 7.05 / 16.0 ms | 7.50 / 17.2 ms | 1.06× |

服务器对两种 bot 统一有 `BOT_ACTION_DELAY = 0.5s` 动作延迟——p95 仅 ~15ms，玩家无感知。

### 4.3 隔离性（不破坏其它模式）

改动全部位于 `game_hongque/` 目录内，未触碰国标等其它模式或 `public/ai/` 共享代码；
`test_hongque_bot_isolation.py` 守卫：虹雀 bot 不拉入其它模式模块、`user_id=2` 仍走牌效、
`user_id=3` 走启发式入口。

## 5. 复现 / 继续验证方法

- **1v3 自战**：1 新座位 + 3 对手座位，**轮换座位**（消庄家/顺序偏差），确定性种子。
- **指标**：锦标赛平均顺位（1-4）+ **95% CI（t 分布双尾）**，CI 上界 < 2.5 视为显著；
  附净分（= 本座得分 − 三对手平均分，分数非零和）。
- ⚠️ **同块 A/B 铁律**：跨块方差极大（同一算法对在不同块上甚至方向相反），
  **单块 200 场的"显著"不可信**；必须同块对比或跨块合并 ≥400 场。

## 6. 后续推进方向（供继续研究）

1. **进攻侧优先**：1v3 自战对防守型微调极敏感；更快听牌、更宽听口、弃牌节奏、
   鸣牌时点，比任何防守细化都更有希望。
2. **E3 听牌安全平局取舍**：唯一被证明不亏损的微调，但 800 场 CI 未达显著线——
   可加大样本或改用 4 座同策略对局鉴别。
3. **鸣牌成本意识**：鸣牌 = 丢门清 +2 base 与门清 1 番 + 暴露方向；但"抑制鸣牌"
   已证明过头——正确写法应是"鸣牌但更早冲刺"，不是"不鸣牌"。
4. **指标改进**：1v3 的"喂分"会稀释小优势，鉴别微调时考虑 4 座同策略对局。
