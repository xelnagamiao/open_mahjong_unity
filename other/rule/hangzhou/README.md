# MIL 杭州麻将（2025）线上计时补则

牌型、财神、财飘、十风、承包和结算依存档 MIL 2025 规则书。线上操作时间依平台房间设置：默认每位玩家每局额外思考时间 20 秒，每次实际操作步时 5 秒；房间自定义值（包括零局时、零步时）生效。

每个需要玩家响应的询问先消耗步时，再消耗该玩家本局剩余思考时间。摸打、自摸/暗杠/加杠选择、吃碰明杠回应、吃碰后出牌和十风和/过选择均采用此合同，不另设线下报牌条款中的 3 秒或其他固定响应上限。吃碰后出牌、杠补后操作属于新的询问，获得一次新的步时，局时继续沿用本局剩余值。

计时按该玩家本窗口首次询问实际发出起算；发送前的计算及出站排队不扣玩家时间。响应到达服务端时停止计费，之后等待其他玩家、广播或处理队列不追加扣时。局时在内部保留小数，避免多次短超时被整秒截断而免费；协议按剩余总秒数向上取整一次，分为剩余局时和剩余步时。

重连、错误动作触发的询问补发及实时观战快照均沿用当前窗口起点和剩余时间，不恢复满步时，不另扣一次局时。询问总时间耗尽后，吃碰杠及十风选择默认过；需要出牌时选择合法默认出牌，打财锁期间保持只能打刚摸牌的语义。下一局初始化恢复房间配置的整份局时。

投票暂停在安全的操作边界生效；待暂停结束及恢复倒计时完成后才发送下一次操作询问。暂停期间的重连仅恢复桌面，不启动行动计时，也不接受牌局动作。

杭州本版本无花、无报听、不能点和及抢杠，因此不存在对应额外响应阶段。系统自动摸牌/杠补及既有机器人表现节奏保持原有语义；局末确认是独立的展示/准备阶段，不消耗下一局思考时间。

服务端首次发送完成是权威起点；网络在途和客户端表现队列的端到端延迟仍受平台公共传输/显示机制约束，未引入客户端可自行重置计时的权限。

纯真人新房默认开启战术鸣牌，房主可以关闭；保存过的关闭配置仍保持关闭。任何实际机器人入座后由服务端自动关闭，移除机器人不会自动重新开启。空座位和观战者不计入机器人判断。鸣牌保护是另一项功能，本版本仍关闭。

战鸣依据原书第六章第4–6项场况变化后改报更高优先级的声明规则，不采用国标的已鸣牌承诺锁。开启战鸣本身不改变普通主询问的实际步时＋剩余局时；有效吃、碰或明杠申请后仍有更高优先级竞争者时，才发出独立5秒的抢断再询问，不叠加房间步时或局时，也不扣普通思考局时。普通思考在申请到达服务端时结账，广播和音效等待不追加扣时。普通“过”仍可参加本张牌的后续抢断，“放弃”退出本张牌的竞争；下一张弃牌重新获得正常选项。

再询问由每位被询问玩家的首次实际发送完成起算；重连、重复补发和观战不恢复5秒，及时到达的回复不因后续队列处理而失效。最终只执行一次胜出的副露；被抢断的申请按公共 `ca` 牌谱记录展示，不改变牌面。独立5秒属于平台线上补则，原书线下3秒条款不用于普通线上询问。
