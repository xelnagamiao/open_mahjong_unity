# 国标麻将（四癞子）

本站四人娱乐规则，标识 `guobiao/four_jokers`。沿用本站标准国标的番种、行牌与支付方式，在牌山中额外加入四张相同的红花癞子。

## 牌张与动作

- 136张常规牌保持不变；默认保留春夏秋冬、梅兰竹菊八张普通花牌，再加四张红花，共148张。关闭普通花牌后为140张，红花仍然保留。
- 红花使用独立牌号59。普通花牌51–58照常补花；红花留在手里，不补花，不计花牌番。
- 红花仅在和牌时替代万、筒、索、风、箭中的任意一张，不能替代普通花牌。每张红花独立替代，可组成顺子、刻子、将或特殊和型。
- 红花不能吃、碰、明杠、暗杠、加杠，不能用它补足鸣牌所需的实体牌。可以打出，但该张红花不能被吃碰杠或点和。自己摸到红花可以自摸。
- 四张红花在手不自动和牌，也不额外加番。红花数不改变起和门槛，不另设软胡折扣或硬胡加番。

## 和牌与计分

将红花替代为常规牌后，必须构成标准国标承认的和牌结构，包含四副一将、七对、十三幺、全不靠、七星不靠和组合龙等。替代后，每种常规牌连同副露最多四张；不能用红花制造第五张同牌。

对全部合法替代及拆分精确算番，采用最高番结果。番种只计算逻辑牌面，实体手牌、摸打记录和回放始终保留红花59。替代不会把实体红花变成桌上可见的普通牌，摸红花也不取得和绝张。

“癞子多面听”默认关闭：先将红花确定为具体常规牌，再从确定后的和牌手牌中移除和牌张，检查全部合法听口；只有唯一听口才允许计单钓将、嵌张或边张，并继续遵守国标番种排除关系。不得为了取得无番和而省略本应计算的独听番。开启后，持红花的多面听均不计独听番；没有红花的手牌不受开关影响。全求人按四副明露及点和将牌判断，不依赖独听提示标记。

默认8番起和，普通花牌不计入8番门槛，达到门槛后花牌计入结算番数F。房间仍可设置起和番、普通花牌、天地人和、错和及战术鸣牌。沿用标准国标支付：

- 自摸：另外三家各付 `8 + F`，赢家收入 `3 × (8 + F)`。
- 点和：放铳者付 `8 + F`，其余两家各付8，赢家收入 `F + 24`。
- 不另收红花分、癞子分或杠分。每盘换庄，每圈四盘。

例：手牌 `111万 123筒 123索 北北北 中 红花`，红花可代中组成将；实际和牌仍按合法拆分和自摸/点和条件精确算番。例：已暗杠四张一万时，红花不能再替代一万参与和牌。

## 房间、统计与性能

独立显示为“国标麻将(四癞子)”，统计分区为“国标（四癞子）”，支持自定义1–4圈四人房。不开排位或自动匹配，不混入标准国标的旧等级统计。不接受普通复式牌墙，可用房间随机种子复现。

结构判断复用癞子牌型求解器，按花色拆分、缓存并合并等价拆分，避免枚举34的癞子数次方。实际和牌精确算番与机器人决策放入已有后台计算池。机器人按结构、有效待牌及可见余牌选择动作，不为每次试打、试摸都精确算番。

Unity与网页对局端根据本人手牌、副露和规则状态，在本地异步计算听牌与番数提示，队列和缓存均有容量上限。服务器不生成提示快照，也不接收对局提示查询。实际和牌权限仍以服务器为准；Web 独立算分工具的接口保留。规则适配遵守[客户端提示计算边界](local-client-hints.md)。
