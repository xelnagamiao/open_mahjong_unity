# 血流成河规则与实现

更新日期：2026-10-12。新个人血流牌谱规则快照版本为 5，双打为 `xueliu-single-table-2v2-v3`。完整换三张设计见 [川麻血流换三张设计稿](sichuan-xueliu-exchange-design.md)。

## 玩法隔离

| 项目 | 弃三张 `sichuan/xueliu` | 换三张 `sichuan/xueliu_exchange` |
| --- | --- | --- |
| 状态机 | `XueliuGameState` | `XueliuGameState` 的独立换牌配置，复用血流流程 |
| 牌 | 万、筒、条共108张 | 同左 |
| 开局 | 弃三张同花色牌，不补牌 | 四家交换三张同花色牌，方向统一随机 |
| 手牌张数 | 庄家11、闲家10 | 庄家14、闲家13 |
| 定缺 | 不单独选择，和牌时须缺至少一门 | 换牌后选择定缺；优先打出该花色，不可用该花色碰杠和 |
| 和型 | 三面子加一对将 | 四面子加一对将，或七对 |
| 花猪 | 手牌和副露合计三种花色 | 仍持定缺牌（包括副露）；三门牌同样不合法 |
| 杠分 | 累计到每次和牌、查叫时 | 开杠即时结算，胡牌另算根 |

## 共同流程

不可吃；首次和牌前可以碰、明杠、暗杠、加杠。无天和，无保留死牌。

碰牌后尚未出牌时，可以对刚碰或原有的刻子加杠；牌墙必须仍可补牌，且不得加杠定缺花色。此阶段只开放出牌和加杠，不产生自摸机会。加杠后正常询问抢杠，无人抢杠则由加杠者补牌；血战仍保持碰后只能出牌。

和牌立即加减分，将本次和牌张放入花区，其他暗手保持隐藏。首次和牌后普通出牌只能摸切，不能碰，但允许明杠；暗杠、加杠只能使用本次摸到的牌。三种杠统一要求：杠后的听牌集合必须包含本人本局此前所有实际和过的牌，重复和同一张按集合处理；未和过的听牌不必保留。杠后按实际手牌更新听牌，后续新和过的牌也加入此约束。可以继续和牌、放铳。三家或四家已和也不提前结束。

一炮多响分别处理每位候选：必和者由服务端直接确认，可选者等待本人选择或托管、超时。自摸或最后一位点和者的下家继续摸牌。首次和牌前，过和后至下一次摸牌前不能点和不高于已放弃分值的牌；自摸不受限。首次和牌后清除顺和限制，按下面的保杠规则判定是否可过。加杠可抢，抢杠后恢复碰并撤销该次杠收益。

## 和后保杠过和

按用户 2026-10-12 提供并确认的 JJ 血流案例实现，适用于弃三张、换三张、单桌双打和双打复式。公开资料未找到该例外的完整条文，因此下列边界是本平台明确采用的实现口径。

- 已和牌后，对手点炮或抢杠原则上必和。若接受这张新和牌会令至少一种原本合法的后续杠变得不合法，则保留“和／过”以及当前合法的杠。不是只要手里有刻子就能过。
- 用当前锁定手牌模拟未来的明杠／摸到第四枚后的暗杠、已有碰牌摸到第四枚后的加杠；杠后的听牌须包含全部已和牌。比较加入本次和牌张前后，是否失去合法杠。已有四枚旧手牌不能当作将来可暗杠的理由。
- 示例（其余面子完成）：`3334` 已和 `4` 后，杠 `3` 仍听 `4`，因此对手的 `2／5` 可过；选择和了 `2／5` 后就不能杠 `3`，随后对手的 `4` 必和。已经失去的杠不能再作为过和理由；多个杠中失去任意一个也可过。
- 无可用补牌时没有保杠例外；复式按本家牌墙判断。只检查手牌结构及能否补牌，不读取暗墙具体内容，不预测第四枚所在位置。
- 双打队友的点炮／抢杠始终可选，自摸维持可选。首次和牌前的顺和、血战规则不变。合法保杠过和不新增顺和限制，不加入已和牌集合；实际选择和牌才加入。
- 真人、重连、机器人、掉线和超时使用同一份服务器动作权限。必和直接执行；可选时沿用已有托管策略（摸切机器人／掉线／超时过，牌效机器人优先和对手），不会把可选误当必和。

牌谱记录 `post_hu_opponent_ron_required=true`、`post_hu_ron_kong_exception="loses_legal_kong"`；回放使用记录的动作，不重新推断旧牌谱当时应否必和。

首次和牌事件仅一人和，由其下一局坐庄；首事件多响则放铳者坐庄；无人和牌则原庄继续。局制为4、8、12、16局，每局重置锁手、杠记录及过和限制。

## 弃三张计分

基础牌型择一：基本胡1、碰碰胡4、清一色6、清碰12。门清自摸加1，每明杠（含加杠）加1，每暗杠加2。无七对、金钩钓、根或情境加番，不按2的幂换算。

设和牌者总分为 F、付款者本局杠番为 K：点和由放铳者付 F+K，自摸其余三家分别付 F+各自K，已和者仍需付款。杠当时不转移分数。

## 换三张计分

| 基础牌型 | 分数 |
| --- | ---: |
| 基本胡 | 2 |
| 碰碰胡 | 4 |
| 七对、清一色 | 6 |
| 金钩钓 | 8 |
| 清碰 | 10 |
| 清七对 | 12 |
| 清金钩钓 | 16 |

基础牌型择最高者；门清加1（点和也计，七对不计），断幺九加1。手牌和副露中每四张相同牌为一根；七对中四张相同可作两对，同时算根。杠上花、杠上炮、抢杠和海底自摸分别相当于增加一根。

最终和牌分数为 `(基础分 + 门清 + 断幺九) × (1 + 根数 + 情境倍率数)`。末张放铳不计海底。无标准血战的三番封顶或自摸额外一分。

即时杠分：点杠由放杠者付3；加杠由其余三家各付1；暗杠各付2。加杠被抢时仅退还该杠，不撤销此前已完成的其他杠。杠分不再次加入付款人的和牌费用。

## 查叫与查花猪

牌墙耗尽后按当前手牌重新判断，已和者也参与。未听牌者向各听牌者支付该听牌者最高自摸可和分，花猪付两倍；弃三张还加入付款者的杠番。听牌判断不要求墙内仍有该张牌。

没有听牌收款人时不转移分数，面板显示“花猪（无人听牌）”或“没叫（无人听牌）”，而非静默显示零分。每次转移四家总和为0。

示例：两名听牌者最高自摸值均为2，另两名分别未听、花猪，且无杠，则最终变化为 `[+6,+6,-4,-8]`。

## 实现与兼容

- `xueliu_rules.py` 保存规则版本和快照；`xueliu_exchange_rules.py` 保存换三张独立番表与倍率。
- `xueliu_hepai_check.py` 检查物理牌数、缺门、牌型和听牌；`XueliuGameState.py` 负责开局、续打和结算。
- `xueliu_bot.py` 以缺门后的合法向听数决策开局、出牌和碰杠，换三张同时比较七对；不会为了通用四面子牌效保留第三门。
- Unity `SichuanTips.cs`、`SichuanFanText.cs` 与服务端同步。新换三张牌谱记录真实 `dingque_suits`，回放恢复标记与提示。
- 版本3的新换三张使用现代番表；旧版换三张牌谱继续使用其旧番表，不从弃牌猜测血流定缺。
- 本文两种子规则为四人个人玩法；双打另见 [血流双打规则](sichuan-xueliu-doubles-rules.md)。弃三张不定缺，换三张的交换与定缺为必经步骤。

回归覆盖开局与交换守恒、定缺约束、合法牌效、重复和牌、抢杠退款、即时杠分、查花猪、无收款人提示及新旧番表隔离。
