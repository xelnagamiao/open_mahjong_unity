# 规则之间怎样相连：机制与证据对照

截至2026-09-23，本轮登记62项来源、91项证据记录，增补57个可区分的目录节点。**91项不是91次已证实的历史分裂**。完整分类与20组机制索引在[evidence-matrix.json](evidence-matrix.json)，原条款定位及限制在[splits.json](splits.json)和[sources.json](sources.json)。

| 记录类型 | 数量 | 可以作出的判断 |
|---|---:|---|

| 规则或牌例见证 | 21 | 某条规则或某个牌例已见；未必知道由什么改来 |

| 跨文本差异或相似 | 16 | 可以比较机制；不据相似推定传播方向 |
| 明示采用或修订 | 12 | 有底本、改编或替代声明；十二项记录不等于十二条独立祖先边 |
| 编纂、传播或机构事件 | 7 | 证明渠道、赛事、软件或编纂过程；规则细节另证 |

分类是研究者的整理，不提高原材料的可靠性。例如现代转录仍是转录，文学牌例仍不等于完整规则书。每条记录保留自己的限制。

## 从宁波出发的严格边界

宁波中发套和宁波竹牌目前是两个牌具见证，不是已经复原的一套完整祖型。Himly 1889／1901的九王三化没有功能说明；Schreiber 1901目录的140张盒装包括四张备用白板，通常入局136。不能用一套补足另一套缺失的玩法。

张德彝1889-01-30日记已记常例牌与可选加花，作者却省略玩法；1894《海上花》有十四张牌例和付款场景；1915 Mauger才在本轮所核材料中提供较完整的十三／十四张及支付说明。三者分别是记述、牌例和规则文本，地点、材料年代及适用范围也不同。这里没有新增“宁波→上海→Mauger”的确定传播线。详见[日记](zhang-diary-1889.md)、[小说原图](haishang-1894.md)、[早期规则](early-evidence.md)。

## 按机制寻找分裂，而不是按省份填父节点

下表的“联系”包含可验证的比较问题。除最后一列明确写“采用”者外，不表示历史传承。

| 机制 | 本轮可对照的锚点 | 联系及剩余问题 |
|---|---|---|
| 入局牌具 | 宁波136常用／备用白板；1924八花选项；1939八花百搭；1961–62十四花加两Big Joker | 入局数量、备用牌、花分与百搭功能四项分开。九王三化名称不能填成百搭。[早期](early-evidence.md)、[NMJL](nmjl-cards.md) |
| 基础手牌数与和牌形 | 1894十四张牌例；1915十三／十四；1931台湾文学的十三／十六对举；1991澳门四／五 | 牌例不等于配牌通则；十三／十六的存在见证不证明福建向台湾传播；简易麻将确实改变基础和形。[台湾](taiwan-1931.md)、[澳门](regional-evidence.md) |
| 特殊和形 | 1924《绘图》的国士十三不搭；1924美国法典限定花色七对；1930日本标准十三幺 | 同名番种可能换义，七对也可能有花色限制。不能把今日定义倒填。[《绘图》](drawing-1924.md)、[美国法典](american-1924.md) |
| 和牌门槛 | 1924法典混合／一倍／清手三模式；1998国标8分 | 最低倍数、指定牌形、加法分数是不同门槛。两者都对花牌能否凑门槛作限制，不足以证明借用。[美国](american-1924.md)、[国标](mcr-versions.md) |
| 副数、番数与加分 | 1894三倍算和；1925严格／宽松的取低／取高及加10／翻倍；1998番种加法 | 有无副、怎样翻倍、同一手如何拆分、封顶、事件奖励各自可变。不能将所有改变合写为一次“废副”。[晚清](haishang-1894.md)、[Wei](wei-1925.md) |
| 谁为普通和牌付款 | 1923 Babcock老新法；1924朱家坚老新法；1998三家底分加放铳者牌值 | 庄家加倍与放铳者加倍的参照改变可直接比较；放铳者多付仍可伴随他家付款。[早期支付](early-text-comparisons.md)、[国标](mcr-versions.md) |
| 未和者之间是否结算 | 1915、1924、1930及1932原文仍见互结；1924法典二人法只付和家；2017宁海观察仍互结 | 和家收三家与败者互结是两个层次。二人法的取消不证明同年四人法也取消，现存旧式也不是“时间落后”的祖先。[美国](american-1924.md)、[宁海](regional-evidence.md) |
| 危险包付与普通全铳 | 1917《清稗》、1924香港书、1925 Wei有条件包付；普通局另有共付 | “大牌危险放铳由一人包”不能缩写成所有点和都全铳；日本普遍全铳的1930年代起点仍缺同期改规原件。[清稗及支付](early-text-comparisons.md)、[香港书](hissho-1924.md) |
| 听牌申告与门前待遇 | 1924林书起手立直；美国Delayed Call；1930首巡立直；1939Maajh起手Set Hand | 都要核申告时点、锁手、奖励、吃碰杠与自摸／荣和资格。相似首巡申告可比较，未证三地互相传播；途中立直的早期规则仍缺。[林书](hayashi-1924.md)、[日本](japan-1930.md)、[NMJL](nmjl-cards.md) |
| 牌墙、末张与补杠 | 1924美国三模式有留十四／摸尽差异；林书末张不弃；2016 TMT墙首补杠；MIL复式自家墙补杠 | “死墙”“末张能否弃牌”“补杠从哪里取”不是同一项；不同组合不宜合成统一古典通则。[美国](american-1924.md)、[林书](hayashi-1924.md)、[国标复式](mcr-versions.md) |

## 可以接实线的采用关系

| 来源或底本 | 后继文本 | 实线的精确含义 |
|---|---|---|
| 澳门1988临时训令 | 1989正式训令 | 明文废止旧本，所核核心条款相续；正式化不等于新玩法 |
| 澳门1989训令 | 1991训令 | 后令明确废止前令，并列传统、简易两类；不是证明民间玩法创于1991 |
| 血战到底地方玩法 | 2016 TMT规程 | 编纂者明说以血战为基础；没有因此证明血战本身的起源 |
| Wright-Patterson与Siamese | 2022 Siamese WP | 署名作者说明结合与改编；旧版完整内容仍须原书 |
| 平成版新报知 | 日本麻雀连盟立直 | 连盟明说底本并参考ねんりんピック；2016公认事件与现行条款日期分开 |
| 1998国标 | 2006 WMO本 | 原书后记明示依据，同时使用其他材料 |
| 2006绿皮书 | 2010 MERS v1.1 | 首段直接指定依据；本轮已核两项操作差异 |
| 国标伞称 | MIL复式方案 | 官方明示底层规则，未说明采用哪一年的MCR版本 |
| 1998国标 | MIL2025补充细则 | 前言和附件明确所据底本；适用2025–2026指定中国赛事 |
| SBR2025主本 | 同文件2V2双打附录 | 明说依主本补充，冲突依附录；取消预先定缺并改变终局条件 |
| 2V2双打 | 附录中的复式形式 | 同书另列复式的牌墙、待机和IMP；不能套到全部双打 |

同书的特别碰法、有花选项或二人变体也有明确的文本包含关系，可在年表中展示。它们与跨地区历史传承、协会正式采用是不同种类的边，应保留原边的类型和注记。

最新原件还给出两组可复核差异：2010 MERS与MIL2025的错和罚分对象、死手后动作范围不同；SBR2025主本和双打附录将“预先定缺”“成和缺门”“同队先和终局”分别规定。复式则另改摸牌来源及待机，见[SBR2025对照](mil-sbr-2025.md)及[国标补充细则](mcr-versions.md)。

## 下一份原件需要解决什么

1. **十三／十六的历史方向**：补1929《麻雀精通》对应原页、福州／温州同期完整配牌条款，再与1931台湾原报比较。只添现代百科不会解决方向。
2. **番副转型与全铳**：需粤港新旧规则同书对照、日本1933／1936同期标准。分别找取消副、取消败者互结和普通全铳，不能只找一个“新式”名称。
3. **途中立直**：1952报知原报或可读的1953制定规程，逐项核申告时点、振听、暗杠、宝牌与供托；不能把1957以后通则整包倒填。
4. **百搭分工**：Liu Yishu 1941、Nguyen Xuan Mai 1950原书，以及NMJL相邻年度卡。优先核可代哪些牌、何时替换、是否计花分，再讨论宁波“王／化”。
5. **地方规则传播**：长沙258、财神／金／混儿、买马扎鸟、捉鸡分别找同地区跨年文本及明确传授记载。暂不以邻省或机制相似画出传播方向。

澳门另核1988、1989、1991原公报，佣金修订与玩法改变分开；同版中葡文不齐仍保留限制，见[版本对校](macau-1988-1991.md)。

矩阵中的空白意味着未核到，不意味着没有该规则。每出现新原件，先更新来源、版本日期与分裂点，再改矩阵、年表和总述。
