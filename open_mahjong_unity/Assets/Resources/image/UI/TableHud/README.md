# 牌桌 HUD 五套设计

主场景默认使用 **原素材经典蓝**。本目录原图来自用户提供的 `新建文件夹 (2).zip`，共 20 张 PNG，原始图片字节完整保留在 `Source/`，文件按图像内容和用途采用英文名称。`source-manifest.json` 的 `file` 对应当前文件名，`originalFile` 保留原始压缩包中的文件名，字节数与 SHA-256 校验值保持不变。原素材包没有“图片11.png”；此说明不额外声明原图的使用许可。

## 查看与切换

- 正式界面保存在 `Assets/Scenes/MainScene.unity`。局况面板已固定为原版修整；设计比较入口、切换栏及消息演示已移除。牌谱仍使用项目原有播放器和牌面。
- 在主场景使用 `Tools → Mahjong → Table HUD → Style` 切换方案，然后保存场景。
- 也可在 `#GameCanvas/GamePanel` 的 `Table Hud Theme` 组件中修改 `Style`。
- `1. Apply HUD Design` 重新应用正式 HUD 布局。请在非播放模式且共享编辑器空闲时使用。

## 信息结构

- Header 只承载规则及子规则，保留原来的规则名称解析。
- Content 保留局况、宝牌/翻牌、本场棒、立直棒及种子入口。
- 独立的 MatchStrip 显示当前场次与局制。特殊规则增加翻牌信息行时，底板和横条随内容高度一起调整。
- 初级场/中级场/高级场来自当前牌桌或牌谱的 `match_queue_type` / `match_tier`，不会读取上一次匹配队列。旧牌谱缺少场次时显示“排位场”等明确的退化文案。
- 房间为 `custom` 时显示“友人房”，赛事房显示“赛事场”；无固定局数使用“无固定时限”。

## 行为与资源

主场景保留原 Button 和已有业务回调；自动播放沿用 GameRecordManager 的状态与逻辑。控制条按牌山/选局、选巡、单步/播放分组，按钮宽度由内容分配，自动播放显隐时重新排列。

五套方案都使用原素材的圆形图标、箭头、白色标签和蓝色底板。其他配色通过 UI 材质保留原图的形状与明暗，只调整颜色；切角边框、圆角轮廓和独立控件布局由 uGUI 补充。`SelectorControlsSheet.png` 与 `ReplayTransportSheet.png`（原图 18/19）使用 Sprite Editor 数据接口切分标签和箭头；切分名称、Sprite ID 和 PNG 字节保持不变。可拉伸底板使用九宫格。素材没有暂停符号，因此暂停状态以两根标准竖线补充。

回归测试数据位于 `Resources/TableHudDemo`：国标采用本地测试牌谱的匿名化副本，立直采用固定种子生成的合法摸切序列。测试直接加载主场景的牌谱播放器；正式界面不创建比较栏，也不会自动填入演示聊天消息。
