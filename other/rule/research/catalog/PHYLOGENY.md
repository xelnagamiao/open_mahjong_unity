# 麻将规则分裂点与证据年表

> 修订：2026-09-23。从宁波早期牌具见证向下核查，不预设今天所有麻将已经可以连成一棵树。
> 主档：[宁波起点与规则分裂点](../ningbo-downstream/PROFILE.md)；[来源簿](../ningbo-downstream/sources.json)；[分裂点登记簿](../ningbo-downstream/splits.json)。
> 日期分为采集、出版、机构成立及规则版本；**能证明某时已有，不等于证明当时发明**。

## 1. 宁波起点的证据边界

1901 年 Schreiber 目录第 193 页记宁波中发：全盒 140 张，通常入局 136 张；1889–1890 是相关采集批次。该条没有配牌张数、成和结构和完整支付法，不能复原为“宁波 1890 标准规则”。[schreiber-1901]

Culin 1895 比较 Glover 与 Wilkinson 牌具，但 Glover 套的空白牌数量前后不一致，不能擅自整理成一个精确总数。Wilkinson 1890 笔记目前核到后来论坛转录，其中十五张配牌尤其需要原备忘录确认。[culin-1895][wilkinson-1890-transcript]

Himly 在 1889 原刊 461 页已记 148 张“宁波竹牌”，1901 原刊 20–22 页再详述，有九王与同化、索化、万化，未说明百搭等用途。同作者两次描述合并；与中发材料分别登记，不强排成 148 张向 136 张线性简化的历史。[himly-1889][himly-1901]

马吊、碰和等前史仍见[旧谱系史料簿](../mahjong-phylogeny/sources.json)。此次没有重新验证全部前史边；它们仍在图中，不代表证据等级有所提高。

## 2. 早期并行打法

| 见证 | 可以确认 | 尚不能确认 |
|---|---|---|
| 《官场现形记》第 31 回，1904 书目归年 | 转录给出 26 副三翻 208；闲家放铳时庄家亦付款 | 本回就是 1903 初刊；叙事省略意味着取消未和者结算；初印本文字已校 |
| Mauger 1915 会议／卷年 | 庄 14 闲 13、四组一对、10 分底、未和者互付差额 | 讲解者故乡就是宁波；卷年等于实际印行年 |
| 《清稗类钞》1917 著录本 | 原页有 136 张及大牌危险放铳包付的诗注 | 所有普通放铳都全付；“包”是百搭“宝”；所收诗文的精确创作年 |
| Babcock 1923 第二版 | New Method 改庄家与出铳支付，仍保留副数和未和者结算 | 新法已见于 1920 首版；它就是现代全铳 |
| 朱家坚 1924 原文的现代重排 | 同书比较庄家参照的旧法、和家参照的新法；新法保留未和者差额 | 旧法简述未提即代表没有未和者结算；与同期书籍的借用方向 |
| 《绘图麻雀牌谱》1924 本 | 无花正文与有花补遗；特别碰法、新新碰法分别改支付、开门和门风参照 | 现存扫描就是 1914 沈一帆本；“新新”就是粤港新章 |
| Foster 1924 | 美国编订法、二人法、去北三人法、单色桌约及赛事计分 | 单色桌约直接传为四川缺一门；作者建议已经普遍实行 |
| American Code 1924 | 同一法典并列三种起和模式；死墙、整手番、二／三人规则存在差别 | 编订者参与足以证明任何一书是另一书的唯一祖先 |

见[早期证据](../ningbo-downstream/early-evidence.md)、[早期文本比较](../ningbo-downstream/early-text-comparisons.md)、[1924 中文本](../ningbo-downstream/drawing-1924.md)和 [Foster 对照](../ningbo-downstream/foster-1924.md)。

取消庄家加倍、改变放铳责任、废除副数、取消未和者互付是独立变量，不能压成一次分叉。十三张或 108 张只能说明可比较的结构，不能单独证明传承。《绘图》的“国士”为十三不搭，1930 日本标准的国士为十三幺；旺子加注也不是百搭。

Wei 1925 对严格／宽松解释的逐条对照补充了同期并存差异：取低／取高、事件加分／翻倍、平和自摸、惯用封顶；都保留庄家倍付及未和者结算。其条件性包付也与普通共付共存。图中只登记并行比较，不画严格解释向宽松解释的祖先箭头。[wei-1925]

## 3. 日本版本桥梁

1930《麻雀新战法》附录可核首巡立直、门前奖励及未和者小副结算。它不是 1909 携牌输入事件，也不是今天立直的整套规则。[japan-standard-1930]

林茂光1924原本提供更早的起手立直见证；东京出版而自述北京、天津北方打法。么半、么二、二四同为庄闲2:1的注额尺度；可选门前一翻／场风与1930条款分别对照，传播方向未证。见[原本校读](../ningbo-downstream/hayashi-1924.md)。[hayashi-1924]

1932《改訂増補 賭博要覧》麻雀章仍描述各家向和者付款、未和者互结差额，并分庄闲支付。这是警务教材的具名记述，不能当作全国统一法令，也不能据未写全铳断言当时各地皆无全铳。[police-manual-1932]

关兆豪“Japanese Classical”明确采用 1962 年底本，本馆改名“日本古典（1962 摘要）”。日本麻雀连盟现行アルシーアル另立版本，不能将现行全铳和无未和者结算倒填到 1930。[kwan-japanese-classical][jml-arushiaru-current]

1936 全铳改革、1952 报知原报及途中立直、宝牌仍有原件缺口。三人麻将也不自动从 1952 报知分出；1924 的另一种三人法与现代日本三麻有不同的牌具删改。见[1930 原典对照](../ningbo-downstream/japan-1930.md)。

现代部分新增“平成版新报知 → 日本麻雀连盟立直”：机构明确采用基础及参考来源。1997 出版、2016 公认和 2026 访问条文分开标注，见[版本比较](../ningbo-downstream/japan-modern.md)。同机构同时使用アルシーアル不等于规则直接传承。[jml-riichi-adoption-2016]

## 4. 十六张、粤港澳、美式

- 1931-07-25 台湾报刊小说〈她！（四）〉明确区别十三张与人物惯打的十六张，原报图像已核。它提供手牌数见证，未给完整牌形、花牌功能和计分；福州、台湾、温州与港式传播方向仍待证。1994 大宇软件为电脑化见证，非十六张形成日期。[xinmin-she-1931][softstar-taiwan-1994]
- HKMA 港式十六张已核到 2025-07-28 修订本：叮牌、即食、拉踢及连拉庄。与台制、日麻、国标机制相似，不等于借用时间和方向已经有证。[hkma-sixteen-2025]
- 澳门 1989 传统版与 1991 传统／简易版分别登记。简易版 112 张、庄五闲四、一组一对成和；禁碰和加杠段落有内部冲突，保留待校。[macau-1989][macau-1991]
- NMJL 1937 成立有机构来源；1961–62 年卡原图已确认十四花、两张 Big Joker、东家双倍。专用 joker 的首次引入和今日八花八 joker 配置的形成仍需相邻原卡，不倒填到 1937。[nmjl-league-history][nmjl-card-1961-62]

香港协会现行版的起和、连庄和封顶只适用于所核版本，不推广为所有香港桌规。

## 5. 川渝及其他地方玩法

青野滋 2017 年宁海田野观察保留副数、未和者结算且无普遍庄家倍付。它与财神宁波玩法分列；2019 论文中的日本源流假说，尚不能当作跨越百年的确定祖先关系。[aono-ninghai-2019]

2015 年 91y 血流文本无需预先定缺，和后锁手继续和；2016 TMT 川麻规定开局定缺、和牌退出，未列换三张。2016 MIL SBR 已有赛事直接记述，馆藏 2025 本不是规则首次存在的年份。[91y-bloodflow-2015][tmt-sichuan-2016][mil-sbr-2016]

血战、血流、缺一门、定缺、换三张和杠分分别追踪。1990 年代／2000 年代的地方报道与口述仍是线索，不能拼成无缺口的祖先链。同理，东北摇宝、下蛋、夹胡可在地方版本中组合；京津混儿、江南财神和红中百搭的相似性不证明传播。

2017 年论文中的 2016 成都赛事观察与地方改法分列。自摸加底／加番、延后加杠收分及退杠分／转雨是可核条款差别；未能定位的改制年代不补写。原“川渝去字禁吃”前身节点也改为未证假说。[aono-sichuan-2017]

哈尔滨的 2020 田野论文明确对照老版与先打后摸的新版，门清资格、暗刻奖励与放铳支付也改变。老版早于 1949、新版于 1980–90 年代流行是口述，节点日期取论文发表年。[aono-harbin-2020]

原年表为战后、1980 年代及 2000 年代安排的若干形成日期没有相应原典，现列“形成时间待证”。

## 6. 图表与审计范围

- 年代行采用注明性质的见证／版本日期；未定年的地方玩法另列研究队列。
