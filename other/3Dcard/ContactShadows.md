# 牌底接触阴影

主工程的 `New Universal Render Pipeline Asset_Renderer` 中新增 **Tile Contact Shadows**。这是独立于主光源的桌布软阴影，保留原来的方向光阴影、牌体光照与描边。它不改变 FBX 或 Blender 模型，也不使用竞品网格、贴图。

在 Unity Project 中选中 `Assets/URP/New Universal Render Pipeline Asset_Renderer.asset`，展开 **Tile Contact Shadows → Settings** 即可调整。运行时所有已取出的池对象都会在下一次渲染使用新值，不需要重新放牌。

| 参数 | 初始值 | 作用 |
| --- | --- | --- |
| Enabled | 开启 | 一键比较原效果与接触阴影 |
| Opacity | 0.36 | 越大，贴桌处越深；可先在 0.2–0.4 间调 |
| Feather Ratio | 0.085 | 软边范围相对牌宽；越大扩散越宽，不改变牌体 |
| Fade Height Ratio | 0.65 | 离桌达到这个牌宽倍数时完全消失 |
| Lift Spread Ratio | 0.08 | 抬牌时增加的最大扩散半径相对牌宽 |

牌宽为 12 世界单位时，默认软边宽度为 1.02，离桌 7.8 后完全消失。高度以现有贴桌留空量为零点，默认留空量仍是 0.02。低处浓、外侧淡；抬起时变宽并淡出。上层叠牌不会在桌布重复画一块浓影。

`TileContactShadow` 挂在现用牌预制体的牌体根节点上。启用时注册，回池、禁用或销毁时移除。`Game3DManager.ContactShadows` 注册现有桌布接触面的动态查询，复用自动贴桌系统的桌布子网格/显式平面。渲染阶段读取最终变换，所以兼容对象池复用、四家朝向、翻牌与父级缩放。独立牌面预览没有桌布注册时不画阴影。

维护预制体时必须保留根 GameObject 的 local fileID `7964087330845181315`，以及原预制体 GUID `b6b976a95574b80408d5b773b7834bb2`。新增组件引用根对象时也使用这个 ID；为导入模型的根对象添加 `stripped` 序列化记录不能另造 ID，否则既有场景中的对象池、牌桌和预览引用都会失效。检查时除按路径加载预制体，还要验证真实场景的反序列化引用。

实现共用一张四顶点、两三角形的程序矩形网格和一个材质，每批最多 128 张牌。片元程序计算圆角矩形的柔和边缘，不采样贴图；仅在牌底附近混合颜色，使用现有场景深度遮住牌体。没有新增全屏 RenderTexture、深度复制、模糊或每牌 Update。额外成本包括 CPU 投影计算、每牌两个三角形和局部透明混合；支持实例化的平台每 128 张以内通常提交一批，不支持时逐牌提交。实际 Web 帧时仍取决于设备，应在目标浏览器上测量。

接触阴影 Shader 定向加入 Graphics 的 Always Included，保留运行时材质所需的实例化变体。不要只删除该引用而保留运行时 `DrawMeshInstanced` 路径。
