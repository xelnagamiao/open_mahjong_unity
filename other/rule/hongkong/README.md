## 清章

默认无花136张，可选择有花144张。三番起糊、十番上限、每局固定轮庄。放铳三至十番分别为32、64、96、128、192、256、384、512分；自摸每家支付对应放铳分数的一半。门前清一番只存在于无花版本，且不允许已经开杠。

包牌只作用于自摸；十二章包与大三元包以较后成立者为准。杠后自摸不包。抢杠加一番，由被抢者支付三家的自摸份额。十三么可以抢暗杠，其他牌型不能。暗杠四张持续公开。九子连环放铳须在和前叫九扉，自摸则只检查完成牌形。

## 十六张详述与简表冲突

数值冲突以“番种详述”为准；详述空项使用简表。下面列出已识别的裁定，版本名包含 `detail`，便于牌谱区别未来修订。

| 番种 | 本版本采用 | 说明 |
|---|---:|---|
| 大四喜 | 160 | 详述；简表180 |
| 字一色 | 120 | 详述；简表240 |
| 十三么九 | 100 | 详述；简表120 |
| 十六不搭 | 50 | 详述；简表60 |
| 双老少顺 | 15 | 详述；简表25 |
| 花上自摸 | 2 | 详述；简表5 |
| 大鸡／大鸭 | 40／20 | 详述；简表60／30 |
| 大七门齐 | 30 | 详述数值为空，取简表 |
| 尾牌连摸 | `5 × 2^(n−1)` | n为连续尾牌补牌数，n>1；按详述公式解释 |

不搭三相、不搭杂龙、三色连刻系列仅在简表列名。本版本将其分别解释为三门不搭数字相同、三门数字并集为1至9，以及数字递增且花色按三门循环的刻子／将眼组合；这些解释属于平台补则。

基础底分为5；此单位也用于暗杠途中奖励，与书中的六底30、八底40一致。普通和牌采用高点法，局部面子组合遵守单式结算；嚦咕两食独立计算两种牌形后相加，底分只收一次。正花、字牌、庄家奖励按原书特例处理。

拉踢按固定玩家身份记账，轮庄不会把债务转给别的玩家。多响使用同一份局前账本同时结算：双方直接胜负先处理，其他赢家不重复清账。三口以上允许欠分者在下一局前斩拉。整场结束时收清未结账款。以上对同时事件与比赛结束的处理属于线上补则。

## 十三张新章：Wiki版本

使用136张，不加入花牌或十六张特有牌形。番表采用公开广东十三张版本，包括七对子，以及原页面明确的“放铳时优先按刻子解释”例外。相同系列的递进番种只取最高项；页面明确的不重复项照办，其余独立番种相加。

七对子按当前平台牌形判定：未开杠的四张同牌可作两对，已经开出的杠不能并入七对。来源中杠与对子关系的未明之处按此线上补则执行；独立规则书明确标注这一点。

本平台使用无货币单位的线性比赛分：一份为 `1底 + 番数`，不设起糊番数或上限。全冲时放铳者支付四份；非全冲支付二份、其他两家各一份；自摸三家各支付两份。十二张落地包自摸，包先；非全冲的九张落地清一色由放铳者付四份。底分单位属于平台补则，不能据此声称复制了商业游戏的金币、房间底注或费用。

公开来源没有定义的动作时序采用清章的一般摸打、吃碰杠、食换及同巡跟张限制；暗杠不开放抢胡；默认固定轮庄、多人荣和按座次头跳。报听后锁手，天听、地听、立直按该公开番表及平台资格判定执行。所有这些选择随规则版本保存在牌谱中。

## 十三张新章：恋绘色版本

以用户上传的文档为底本，名称由用户指定，不属于香港麻雀协会认证版本。默认144张、有花，允许选择136张无花。普通牌形为四组面子加一对，不设七对子或报听。三番起和（计花与自摸），庄家和牌或流局连庄；多人和同张牌默认截胡，十三幺优先于普通牌形，再按距出牌者的座次排序。

开局由东家完成自己的补花，补入花牌仍由东家继续，之后依次南、西、北。操作仍是逐张点击或开启自动补花。暗杠牌持续公开，只允许十三幺抢暗杠。吃碰后不得打出同一张，文档未规定的两端食换禁令不额外加入。

番表：平和、无花、每张正花、自摸、门前清、每组番牌、抢杠、海底捞月各一番；一台花二番；花和、对对和、混一色三番；花幺九四番；小三元五番；小四喜六番；清一色七番；大三元、连杠开花、大花和、坎坎糊八番；字一色、清幺九、九莲宝灯十番例牌；天地人和、大四喜、十三幺、十八罗汉十三番例牌。杠上开花为一番加自摸一番，共两番。例牌只取最高一项，不叠加其余番数。

采用原文图片的分数表，放铳由一人支付下表全额，自摸由其余三人各支付一半，包自摸者支付三份自摸分。普通牌累计超过十三番时封顶十三番，这是补齐原表未列区间的线上裁定。

重复计算及文字歧义按以下方式执行：

- 原文称门前清“打花牌一般不作计算”，本版本只在无花136张馆规中计门前清。有花牌墙即使没有摸到花也不计门前清；无花牌墙不凭空增加“无花”一番。
- 花和三番、大花和八番、连杠开花八番均已含自摸，不再叠加自摸。坎坎糊按第五节“不另计自摸”执行，也不加门前清、对对和。开过暗杠不算坎坎糊。
- 小三元、大三元已含三元番；花幺九不加对对和；小四喜不加必然混一色，但可计门圈风；一台花不再计同系列正花。九莲宝灯检查完成牌形，不额外要求放铳前九面听。
- 原文提及部分馆规的“出杠”不启用。生章明杠只包紧接着的杠上自摸，补花或后续摸打中断该责任；大三元包优先于后来成立的包十二张，同巡跟打对方刚打的同牌吃碰不成立十二张包。
- 放弃碰同牌，或放弃同水路和牌，须到自己下次摸牌才解除；同巡出现更高番数可以和。补牌也是摸牌。文档没有划分独立水路的复杂多面听，平台统一限制已放弃番数及以下的点和。
- 原文诈和赔偿写256，与十三番表384不同。本平台不模拟线下诈和：服务端拒绝非法和牌，不生成自报诈和罚分。错误配牌、骰子及手工码牌的违规操作同样不作为线上动作。

## 新章十三（恋绘色魔改）

香港新派清章（恋绘色魔改版）是恋绘色以香港麻将（新派清章）为原型灵感，深度魔改而来的个人规则，在保留了三三制（混一色和对对和三番、清一色七番）骨架及番数与分数非线性对应关系的基础上大量增加国标麻将、立直麻将和中庸麻将的部分番种/役种/和种，以期达到更丰富的造牌体验，并避免了番数增加后分数过于膨胀等问题，总之是融合了香港麻将、立直麻将、国标麻将和中庸麻将的大杂烩。

以用户上传的《香港新派清章（恋绘色魔改版）》为底本，按作者更正命名为新章十三（恋绘色魔改），归入新章。此为独立的自定义版本，与新章十三（恋绘色）分别提供。固定使用144张。允许四组一对、可含相同对子的七对、十三幺、十三不靠；十三不靠须为147／258／369三门排列与字牌中的14种不同牌，并且九张筋牌或七种字牌至少完整一组。不声明报听。

开局同一玩家补完全部花牌及新补入的花牌，再轮到下一家；每次操作仍只补一张，可沿用自动补花。七花、八花不直接和牌，必须完成合法牌形。至少有一番非花番，且移除所有花牌番分和附加分后，基本分经修约须达30分。

暗杠公开牌的种类，牌面展示采用立直麻将样式：两端倒扣、中间两张明示；只有十三幺可抢暗杠。默认庄和连庄，流局仅庄家牌形听牌时连庄；流局听牌不额外要求已经满足起和分数。每连一次庄，下一局所有赢家的基本分加2分，轮庄归零。每次连庄重新派生牌墙种子。

### 付款、包牌与过水

基本分为a：自摸三家各付a；点和放铳者付3a−60，其他两家各付30。赢家收入始终为3a。

房间可选择截和或一炮多响。截和按放铳者的下家→对家→上家顺序选择最近的合法宣告者，不比较番数。其他合法宣告和牌但被截和的玩家，其常规30分由放铳者代付；具备和牌资格但选择过牌者仍照常付30分。例如基本分60、甲放铳，乙丙宣告而乙和牌，甲付150、丙付0、丁付30，乙收180；乙丙丁均宣告时，甲付180，其余两家免付。

一炮多响按每位和牌者分别常规结算，再累加收支；和牌者之间也照常支付对方的30分，不套用截和豁免。包十二张、包满贯仍按各自包牌条款处理。抢杠和牌沿用相同宣告优先级及付款规则。

- 包十二张：四副明面子必须全部来自同一供牌者；该人包付赢家的全部3a，自摸或点和都适用。暗杠不算别人提供的面子，加杠保留原碰的供牌身份。
- 包满贯：一次吃、碰、明杠使公开面子已能保证准满贯以上牌型时，最后供牌者承担责任。例如第三组三元刻、第四组风刻、第四杠、第四副相同顺子、第四副连续同门刻子。自摸包3a；点和由责任者付2a、放铳者付a。同一人兼放铳者则付3a。包十二张优先。
- 同一巡放弃点和某张牌，仅限制再次点和这一张；其他听口不受影响。自己的下次摸牌不解除该限制。依原文“一巡”定义，在北家弃牌响应全部完成后清除本巡限制。
- 自己曾打出的牌，直到本局结束都不能点和该张；不把其他听口一并判作振听。自摸不受这两项点和限制。

## 线上执行

服务端决定合法动作、番数和付款。客户端不能提交番数或覆盖结算。牌墙随机种子沿用项目承诺与结算后公开机制。未按时应答自动跳过可放弃动作，轮到打牌则选择合法弃牌。断线重连应恢复同一动作窗口与账本。

有花规则沿用国标的逐张补花交互：每次「补花」只亮出一张花牌并补入一张牌，也支持现有的自动补花开关。协会清章、十六张开局按东、南、西、北轮流处理本轮持有的花牌，补入的花牌留到下一轮处理；新章十三恋绘色与新章十三（恋绘色魔改）采用上文同一玩家补完再轮转的顺序。摸牌或杠后摸到花牌也进入同一补花窗口，超时自动完成当前一张，重连保留待补状态。

线下的错误配牌、裁判黄牌、读牌礼仪等不模拟为可操作的违规动作；服务器直接拒绝非法请求。赛事报名、裁判处罚和赛事总时长不是普通房间的牌型规则。
