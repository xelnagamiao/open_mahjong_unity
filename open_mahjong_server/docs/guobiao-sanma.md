# 三人国标

`guobiao/sanma` 是国标的独立子规则，采用本项目标准国标的番表和操作流程。它只减少人数与万子牌池，并按实际人数调整轮庄和收付。

- 三个座位：东、南、西。万子只保留一万、九万各四张，删除二万至八万；筒、索、字牌不变。
- 开花牌时共 116 张，关闭花牌时共 108 张。每人 13 张，庄家多一张；补花规则继承国标。
- 保留吃、碰、明杠、暗杠、加杠和抢杠和。吃牌权属于放牌者的下一家；多人申请和牌按离放牌者的顺序优先处理。
- 北风是普通字牌，没有拔北。场风仍依次为东、南、西、北，每圈三盘；东风战三盘，半庄六盘，全庄十二盘。每盘换庄，无连庄；跨圈时交换两侧邻家，使三人分别经历两种相邻关系。
- 默认八番起和，花牌不计入起和门槛。保留起和番、错和、天地人和、战术鸣牌、鸣牌保护、计时和观战等现有设置。依赖万子顺子的番种自然无法组成，其余番值不变。

若和牌番数为 `F`，自摸时两家各付 `F + 8`，赢家得 `2(F + 8)`；点和或抢杠和时，放铳者付 `F + 8`，另一家付 8，赢家得 `F + 16`。错和分付模式扣 20、另外两家各加 10；固定扣 40 模式沿用现有规则。

现有复式牌墙按四人分区，三人子规则明确拒绝使用这类密钥。三人牌谱和三人的对局记录正常保存，不并入四人标准国标的累计、番种和场景统计。

服务端测试位于 `gamestate/game_guobiao/test_sanma.py`、`test_sanma_branches.py` 和 `room/test_guobiao_sanma.py`，覆盖牌池、番表一致性、全部座位、十二盘轮庄、结算、错和续局、抢杠竞争、房间容量及完整牌谱。Unity 的 `Assets/Tests/GuobiaoSanmaValidation.cs` 提供开发客户端与 Editor 的规则、提示、座位、局名和计分协议验证入口。客户端的跨圈换位只显示三名玩家，计分板与终局排名按实际人数显示，并在返回四人规则时恢复第四名玩家的位置。完整多人、观战和回放验证产生的本机报告放在 Git 忽略的 `.om_workspace/` 中。
