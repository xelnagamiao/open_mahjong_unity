## 出身与自测画像

**自测口径**：四席同策；每组 **126 全庄**（国标 4 风各 4 局 → 每组约 **2016 局**）。两组不相交全庄样本配对合计 **4030 局**。牌山在测量方侧固定可复现（本说明不写种子号；数字描述算法行为画像）。

**总表（配对）**

| 指标 | 数值 |
|--|--|
| 流局率 | **2.53%**（102/4030） |
| 和牌率 | 97.47% |
| 副露率 | 69.34% |
| 均和番（非花） | 12.31 |

**主番频率（≥4 番，占和牌；取其中一组约 1966 次和）**  
三色三步高 **34.4%**（676）、不求人 8.3%、和绝张 7.4%、三色三同顺 6.4%、七对 6.2%、花龙 5.5%、组合龙 4.3%、五门齐 4.3%、混一色 3.7%、碰碰和 1.5%、全带幺 1.5%。  
同口径下早期快照约 10 全庄时三色三步高约 **24%**，本版升至约 **34%**，明显过热。

人类参考中职业选手三色三步高约 **25.5%**；本版 34% 过高。群内共识：总流局/副露等陪打向指标尚可，但主番分布偏离——三色三步高过热，三同顺相对偏低，五门齐/混一色/碰碰等主体番偏少，和绝张/不求人/七对偏「机器」；有不求人时不计门前清与自摸。三色三步需压（粗目标 &lt;28% 量级）属后续方向，**未在本版强做**。

**与上一版对照**（12 全庄锦标赛）  
上一版：2026-07-31 前后讨论、哈基明此前已实现的快照；因不达预期**未提交**。相对该快照：2 本版 + 2 上一版时均顺约 **2.17 vs 2.83**；1 本版 + 3 上一版时约 **2.08 vs 2.64**（本版略强）。上一版自战流局明显高于本版，约 9% 量级／小样本，仅作背景。

## 决策骨架

- 优先靠近「≥8 番且可实际和牌的听」；结构听不够番视为未听；一摸前瞻进合法听
- 合法听进张只计够番等待；仅自摸听 ×0.35
- 听牌并列：少仅自摸听种 → 多可荣听种
- 箭刻/圈风/门风碰可持平向听；门清合法一摸进张提升可开副露
- 绝张、尾巡 `wall < 16`、空墙海底/妙手假想番
- 七对向听严格优于一般型时不鸣；不求人门前不死守
- 起和番跟随房间 `hepai_limit`（默认 8）

在 `open_mahjong_server` 目录：

```powershell
python -m pytest server/gamestate/public/ai/test_guobiao_heuristic_smoke.py -v -k two_quanzhuang
```

覆盖：合法听 vs 假听、尾巡海底假想、仅自摸听权重、绝张假想、鸣牌推进/番牌碰/七对护航、`hepai_limit`、变种 `sub_rule` 拒绝加座、弃牌金标、短全庄接线 smoke。

## 服务端短 smoke

**两个全庄**服务端短 smoke 已通过：四席高性能罗伯特、`guobiao/standard`、`hepai_limit=8`、`tactical_call=true`、fast_sleep/headless。单全庄约十余分钟；63 全庄仍挂起（勿默认跑）。

国标变种（小林/K神/蓝氏等）：服务端拒绝加座；Unity/Web 隐藏或禁用并提示「暂未支持」。
