# 广东麻将 MIL 2023 花鬼规则

本平台采用存档《广东麻将（推广）竞赛规则（试行2023版）》。这是140张、四张花牌作鬼的版本，位于广东麻将大类，与既有推倒和子规则分别建房。底本为 [MIL 广东原始规则书](../MIL_rule/广东麻将（推广）竞赛规则（试行2023版）.pdf)，子规则标识为 `guangdong/mil2023`，细则版本为 `mil-guangdong-2023-om1`。

## 牌张和动作

万、筒、条及七种字牌各四张，梅兰竹菊各一张，共140张。四张花牌作为鬼留在手内，不补花；鬼可以替代任一普通牌，可以打出，但打出的鬼不能被碰、杠或点和。鬼不中马。没有吃牌。

庄家起手十四张，其他三家十三张；普通和形为四组面子加一对将，另有七对、四鬼、十三幺。七对允许未开杠的四张同牌算两对。计算替代后的闭手牌时，每种逻辑牌最多四张，已公开的碰、杠不计入这个逻辑上限；实际牌张库存仍严格限于原来的140张。

碰后只能出牌，须再次摸牌才能暗杠或加杠。杠后从牌墙末端补牌，普通摸牌从前端取牌，不留固定死牌墙。最后一摸之后不能开杠，最后弃牌无人和即流局。仅加杠开放抢杠；同张牌多人和时，沿行牌方向取最近一家。

依原书第三节第15条、第五节第5条，暗杠的牌种公开：先公示，再扣住两侧两张，中间两张正面显示。其他玩家未公开的手牌、普通摸牌及听牌提示仍按所属视角发送。

## 番种和门槛

| 番数 | 番种 |
| --- | --- |
| 1 | 自摸、门清 |
| 4 | 碰碰和、混一色、抢杠、海底 |
| 5 | 杠上花 |
| 6 | 七对 |
| 8 | 清一色 |
| 12 | 幺九、小三元、小四喜、天和、地和、四鬼 |
| 16 | 九莲宝灯、大三元、大四喜、十三幺 |

原书要求同时达到两番和四分。建房默认启用“四分起和”；关闭这一推广选项后仍须至少两番。除原书允许的这个选项外，不开放改变鬼牌数量、马牌数量或番值的馆规。

必然包含的番种不重复累计：七对、十三幺不再加门清；九莲不再加清一色、门清；幺九、大四喜不再加碰碰和；天和、地和不再加自摸、门清；杠上花不再加自摸。四鬼只复合天和、地和、海底、杠上花、抢杠五种偶然番。若同一手牌有多种替代或和形，比较所有合法解释，采用最高分。九莲按和牌前的九面听牌形检查，不能仅凭和牌后的多重集合判断。

## 支付和奖马

基本分等于番数之和乘分数系数。点和由放铳者支付一份基本分；自摸由其余三家各付一份；抢加杠由被抢杠者支付三份。

| 杠的来源 | 成立后的即时支付 |
| --- | --- |
| 点杠 | 点杠者付3分 |
| 用刚摸到的牌加杠 | 其余三家各付1分 |
| 用原手牌加杠 | 不计杠分 |
| 暗杠 | 其余三家各付2分 |

加杠被抢时不成立、不计杠分，恢复原碰牌。流局退还本副所有杠分。和牌结算只追加和牌及马分，已结算的杠分不重复加入。

自摸时翻剩余牌墙前端连续四张马牌，不足四张取全部剩余牌，不补足。鬼不中马，每中一马，和牌者从各应付方增加收取1分。马位以本副庄家为基准：庄家为一五九及东；下家为二六及南中；对家为三七及西发；上家为四八及北白。

点杠后立即补牌和，由点杠者独付三份基本分及三份马分；如果补牌后又加杠或暗杠，再补牌和，则恢复普通自摸支付。

## 系数叠乘的平台补则

原书第八节分别规定无鬼系数为2、打出过N张鬼的系数为2的N次方，没有明确两者同时成立时如何合并。用户于2026年10月2日确认本平台连续相乘：

`系数 = (和牌实体手牌无鬼 ? 2 : 1) × 2^本副已打出鬼数`

例如，出过两鬼且最终无鬼，系数为8；出过两鬼且仍持鬼，系数为4。此项是用户确认的平台补则，不声称为MIL官方释义。

参考的[世界麻将巡回赛广东规则](https://worldmahjongtour.live/广东麻将规则/)分别描述无鬼翻倍和每出一鬼翻倍，提供了连续叠乘的外部玩法依据。但该版本使用136张翻鬼，其他番值及马规则也不同，不能整套替代MIL 2023底本。[麻将运动技术等级评定中心介绍](https://www.mahjonget.com/official.html)用于核对140张花鬼版本的归属，不用于补定这一系数歧义。

## 过水与线上流程

放过可点和的牌，或自己打出自己的和牌张后，在本人再次摸牌以前，不得再点和基本分小于等于该次放过分数的牌；更高基本分仍可点和。碰牌不解除这一门槛，自摸不受它限制。比较的是乘过系数的基本分，不是未乘系数的番数。

和牌者下一副坐庄，流局庄家保持。平台按建房选择进行4、8、12或16副，每副均计入局数。开局使用平台可复现的牌墙与发牌记录替代实体骰子、码墙；动作按钮和既有碰、杠、和配音替代现场报声。所有玩家的结算手牌公开供核对，牌谱保留鬼的实体牌、替代结果、出鬼次数、杠分、奖马顺序和责任支付。

原书关于触牌、错报后的现场裁判罚分、争议仲裁及比赛场地的规定不伪造为线上操作。服务端拒绝非法动作，规则判定与支付由权威状态机执行。
