规则书正文

宜兴麻将总共使用144张麻将牌，其中包含万条筒各36张，东南西北中发白各4张，花牌春、夏、秋、冬、梅、兰、竹、菊各一张。基本术语

花牌：春、夏、秋、冬、梅、兰、竹、菊，抓到花牌必须补牌，花牌补牌不算杠开，胡牌时每张花牌计1花。补花和杠从牌山后摸

杠：4张相同的牌可以开杠，暗杠需要亮明一张

放铳（冲）：自己手中的牌组合成胡牌格式，所需最后一张牌由他人弃出时即可胡牌，由放铳者一人独付。

自摸：自己抓来所需最后一张牌而胡牌，由其余三家付。

打牌流程

游戏为四人成局，独立对抗。 开局每人13张牌，庄家14张

4个人随机入座，轮流值骰子，点数最大的为东家，然后东家再掷色子，掷得点数为几，以自己那个位置逆时针数的那个位置就是东位，3，7，11就是对面座位，5 9就是自己座位，2 6 10就是自己座位的下家，4，8 12，就是自己座位的上家，然后第二大点数为南，以此类推

若庄家胡牌则继续坐庄连庄，若闲家胡牌则由上一局庄家的下家成为下一局庄家，直到东家再次做庄为一圈，打满4圈为一将，本地一般每次组局打满3将，时间4小时到6小时左右，线上可改为一将一结算，一将结束，最后一局赢得人重新掷色子定东位，然后4人再次轮流掷色子，点数最大为东位，以此类推

东家起手继续掷色子，掷到几，就从哪面摸牌，留最小点数堆牌，比如掷出2 3，共计5点，既自己牌堆开始，留最小点数2堆牌

玩家按照逆时针方向依次摸牌、摸完牌后，东家补花牌出牌后。下家才可以补花牌，出牌时，可以吃（只能吃上家）、碰、杠（包括明杠和暗杠）。 但不能吃、打同一张牌。放弃过的碰张、胡张，在一圈内不能再碰、再胡。

胡牌规则

宜兴麻将能吃能碰无财神，放冲独付。 至少2花可自摸胡，至少3花可放冲胡。1花时只能胡大吊车，即独吊，无花不能胡大吊车

一、基础单牌型（固定花数）

1. 混一色：6花

2. 碰碰胡：6花

3. 门清：4花

4. 清一色：8花

5. 七小对：10花

6. 全风板：13花

二、牌型叠加规则

2种组合：总和 -1

3种组合：总和 -2

三、常用复合牌型（直接查表）

混一色 + 门清 = 9花

混一色 + 碰碰胡 = 11花

混一色+碰碰胡+门清 = 14花

清一色 + 门清 = 11花

清一色 + 碰碰胡 = 13花

清一色+碰碰胡+门清 = 16花

注：胡牌满足两种牌型时，花数相加后减去一花；满足三种牌型时减去两花，以此类推。

花牌/刻子/杠 额外加花（单独累加）

1. 四季花/梅兰竹菊（花牌）

单张 = +1花

2. 箭牌/本门风

• 明刻（碰）：+2花

• 暗刻：+3花

• 明杠：+4花

• 暗杠：+5花

3. 别家风牌（非门风东/南/西/北）

• 明刻（碰）：+1花

• 暗刻：+2花

• 明杠：+3花

• 暗杠：+4花

4. 万/条/筒（普通序数牌）

• 明杠：+1花

• 暗杠：+2花

算点 1花一点

2花 破门清的状态下只能自摸，胡牌才能加一花，当地俗称小3花

3花 破门清可以胡放冲，胡牌加一花，既4花

{番型花数+额外加花}乘以特殊翻倍，最后多少花算多少点

特殊翻倍（总花数最后相乘）

• 杠开、海底捞月、大吊车：总花数 ×2

抢杠胡，只能抢先碰后补杠的杠，大明杠和暗杠抢不了，1包3家，即翻3倍

tips ：

最好加个带7对和不带7对的选项，我们打的一般不带 带得话7对默认10花

手里胡放冲的风牌字牌，算花少一花，自摸风牌胡牌，算花不少花 最后一张海底可以弃摸，摸了不糊就必须打这张，别人胡这张，翻3倍

吃牌 不能吃啥打啥 比如46吃5不能打5，45吃3不能打36，但是手里仅剩4张牌牌时，吃完这手可以混独吊时，可以吃啥打啥，俗称过水
