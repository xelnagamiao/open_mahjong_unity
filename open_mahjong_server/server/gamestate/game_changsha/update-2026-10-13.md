# 长沙麻将更新说明: 卡摸、封顶和骰子开杠

这次更新增加三项玩法设置，并把开杠后多张补牌的处理补完整。创建房间时就能确定规则，所有玩家按同一套规则打完整场。

## 1. 卡摸: 小胡只能自摸，大胡仍可接炮

创建房间新增“卡摸(小胡仅自摸)”开关，默认关闭。

开启后，普通小胡只能胡自己摸到的牌，不能胡别人打出的牌。大胡仍可以接炮。清一色、碰碰胡、七小对，以及地胡、杠上炮、抢杠胡、海底等原有情境大胡，继续按现有规则判断。

关闭卡摸时，继续使用原来的小胡接炮规则。听牌提示会跟随设置，标准小胡会标明仅可自摸。

## 2. 封顶: 可以封大胡数量，也可以封最终分数

经典庄闲计分和不区分庄闲计分都可以选择下面三种方式，默认不封顶。

| 方式 | 怎么算 | 例子 |
|---|---|---|
| 不封顶 | 按原来的大胡、庄闲和鸟规则计算 | 保持原计分 |
| 大胡数量封顶 | 最多按设置的几大计基础分，鸟继续另算 | 最多三大，中鸟仍可翻倍 |
| 最终分值封顶 | 基础分和鸟都算完后，限制最终付款分数 | 含鸟原本应付96，封顶64就付64 |

大胡数量沿用现有牌型权重。例如某牌型原本按多大计算，仍按它原来的“大”数累计，再应用上限。

封顶按每个付款方分别计算。自摸且封顶64时，三家各自最多付64，赢家合计最多收192。

同一次开杠中，同一个付款方给同一个赢家的多笔分数共用上限。例如同一个玩家胡了两张补牌，每笔原本48，封顶64时，第一笔付48，第二笔只再付16，合计64。若是两个不同赢家，各自有独立额度。

四喜、板板胡等起手胡不受任何封顶限制，继续沿用原来的即时计分。

数量提供2大、3大、4大和自定义。分值档位根据计分方式、大胡底分和扎鸟数量生成。例如不区分庄闲、大胡底分8、扎2鸟时，常用档位是32、64、128分；经典庄闲模式对应28、56、112分。也可以选择自定义，输入1到1000000的整数。

这些选项只在创建房间时设置，开局后固定。房间详情会显示卡摸、封顶方式和具体数值，重连后沿用原设置。

## 3. 骰子开杠: 从牌墙末尾按墩定位

房间只提供开2张和开4张。明杠、暗杠、加杠，以及连续开杠，每一次都会重新掷两个骰子。普通“补张”继续补一张，不使用骰子取牌，也不会因此新增锁手。

取牌时，从最后一墩开始向前数，优先用两个骰子的点数之和定位。开2张取这一墩，开4张再取下一墩。

只有起始墩不存在，才改用较小骰子的点数。已经找到起始墩，但下一墩不足时，就拿实际存在的牌，不重新改位置。

以骰子5和6为例:

| 剩余牌 | 开4张 | 开2张 |
|---|---|---|
| 15墩、30张 | 取倒数第11和12墩 | 取倒数第11墩 |
| 11墩、22张 | 只取第11墩现有两张 | 取第11墩 |
| 10墩、20张 | 11墩不存在，改取第5和6墩 | 改取第5墩 |
| 4墩、8张 | 两种位置都不存在，开出0张 | 同样开出0张 |
| 21张，第11墩只有1张 | 取这1张 | 取这1张 |

半墩也算一墩。补张或开杠留下的尾部半墩会继续按半墩计算，连续开杠不会把它重新拼成完整墩。

海底牌始终预留，开杠不能取走。选中的墩包含海底时，跳过海底，其他牌照拿。

如果最终开出0张，已声明的杠仍然成立，玩家仍然锁手，不补牌，也不另外打牌，直接由下一家继续摸打；只剩海底时进入原有海底流程。

## 4. 同一次开杠的多张牌，按一个整体处理

开出来的牌会摊开，所有玩家都能看到。服务器按以下顺序处理:

1. 先用开杠前锁定的原手牌，逐张判断本家能否自摸。多张能胡时，手牌牌型去重，按可胡张数累计杠上开花，只扎一次鸟。
2. 本家不能胡或选择过，再判断其他玩家能否接炮。同一张可以一炮多响，不同补牌可以有不同赢家，同一个玩家也可以胡多张。
3. 本批所有接炮共用一次鸟，开杠者是付款方。出现多笔胡牌结果时保留本局原庄。
4. 没有人胡，再判断本家能否续暗杠。所有合法目标都可以选；选中后，其他不用的补牌先摸切，不再次询问其他玩家，再开始新一轮骰子开杠。
5. 本家不续杠时，剩余补牌摸切。他家鸣牌最多执行一个，按杠、碰、吃的顺序，再按离开杠者的座次确定。

锁手后，只能按规则自摸、暗杠或摸切刚摸到的牌。客户端发来原手牌的出牌请求时，服务器仍只处理它指定的补牌，避免误删原手。

真人操作、AI、超时和重连使用同一批次状态。超时放弃胡牌会记录过手；过期后才到达的自摸请求不会被接受。实际摸牌刷新过手限制，自摸仍不受普通接炮过手限制。

## 5. 回放和显示也一起修正

- 重连、实时观战和牌谱跳转能恢复当前还没处理完的公开补牌。
- 只打出一张补牌后跳转，剩下的牌仍保持公开，不会整批消失。
- 切换牌谱明牌显示时，公开补牌只显示一次。
- 连续暗杠先收走公开牌和原手中的目标牌，再建立副露，避免重复显示或实体牌不够用。
- 实时和回放倒牌前，先等补牌队列处理完并回收公开牌，再展示和牌手牌。
- 开杠自摸的回放、跳转和计分板只使用真正可胡的补牌，不混入同批不能胡的牌。
- 牌谱记录最终实收分，包含鸟和封顶，与实时结算一致。自摸封顶10时，记录三家各付10、赢家共收30。
- 骰子取走牌墙中间的牌，回放也按记录的实际位置移除，剩余牌墙顺序保持一致。

旧房间里开1张、开3张的配置，加载时归一为开2张。原有卡摸和封顶配置缺省时，分别视为关闭卡摸和不封顶。扎鸟沿用现有显示方式。
