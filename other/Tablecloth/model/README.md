# 牌桌模型

本目录保留已有 Desktop / DeskTopNew 文件，当前独立边框为 V8。

- `TableFrame_Upright_V8.blend`：可编辑模型，Blender Z 向上。
- `TableFrame_Upright_V8.fbx`：Unity 使用，Y 向上。
- `TableFrame_Upright_V8.obj`：通用交换模型，Y 向上。

## 当前尺寸

以布面为高度 0、布面中心为原点，单位沿用项目坐标，不代表毫米。

| 项目 | 尺寸 |
| --- | ---: |
| 内开口 | 430 × 430 |
| 外轮廓 | 471.101974 × 471.101974 |
| 单边水平宽度 | 20.550987 |
| 布面以上竖直内壁 | 5.30 |
| 内圆肩径向宽 / 高 | 1.48 / 1.14 |
| 水平顶面径向宽 | 17.870987 |
| 顶面高度 | +6.44 |
| 底面高度 | −12 |
| 总高度 | 18.44 |

V8 在已确认 V7 的基础上，将可见内壁从 3.53 提高到 5.30，增加约 50%。同时缩小水平顶面，补偿升高带来的透视变宽。补偿依据当前 MainScene 相机的位置、旋转和 59° 视角；不是任意视角下都保持同样的屏幕宽度。

内壁垂直、顶面水平，内外小圆角各有 6 段，闭合 80 四边面 / 160 三角面。Unity 因 UV 和法线接缝可拆分顶点。几何为项目原创，参考成熟牌桌的结构比例，未复制第三方网格或 UV。

## UV 与材质

UV0 `FrameSurfaceUV` 的 20 个条带岛与 V7 完全一致，可继续使用 `../Edges` 的 17 张底纹、2 张默认共享光照及可选饰线。本次只调整几何，不重新绘制配色、木纹和 PSD。

内壁变高后，其竖向纹理和窄接触线随该面比例伸展，沿边方向不变。原接触线高度约 0.12，现约 0.18，需以最终游戏相机判断。旧平面方环 PNG 不适用于此模型的 UV0。

## 主场景组织

模型、默认材质和边框组件直接序列化在主项目 `Assets/Scenes/MainScene.unity`，边框为 `DeskTopNew` 下的 `Table Frame (3D)`。编辑模式和 Play 使用同一份已保存网格；运行时只处理材质实例和纹理切换。

主项目 `Assets/TableFrame/SceneAssets/` 保存 `DeskTopNew_ClothOnly_V8.asset` 与 `Frame_OrangeWood_V8.mat`，由场景直接引用。纯桌布网格保留原顶点、UV、法线和材质槽，仅移除旧平面边框的三角索引；自定义平面边框仍可切回原 FBX 网格。

原桌面为导入缩放较大的 FBX，边框子对象的局部变换补偿父级导入变换，实际世界比例为 1。不要只改其局部缩放来推断模型尺寸。

原 Desktop 文件保持原字节。V7 模型、旧运行元数据及修改前主场景，可在本机 `.om_workspace/20260913-scene-frame-v8/backup/production-before-v8/` 与 `archive/` 恢复。过程脚本和验证资料保存在同工作区。
