# 山西麻将（MIL 试行2023版）

平台规则号：`shanxi`；子规则：`shanxi/mil2023`；实现版本：`mil-shanxi-2023-om1`。

底本为存档的 [MIL《山西麻将（推广）竞赛规则（试行2023版）》](../MIL_rule/山西麻将（推广）竞赛规则（试行2023版）.pdf)，全文17页。此版本不加入地方癞子、花牌、抢杠、吃牌或其他番表。

## 牌与动作

- 136张牌，闲家13张、庄家14张；没有花牌、癞子。可以碰、直杠、暗杠、加杠，不可以吃牌。
- 原书将万、筒、条、风作为四种花色，并将东南西北中发白全部列入“风”。数牌按牌面1—9点，七种风牌均为10点；全风牌也满足该书清一色定义。
- 必须先报听才能和牌。报听在自己出牌时进行，将所切的那张牌暗扣放入牌河。至少一个结构听口达到6点，且该牌在本人可知范围内尚未绝张。
- 报听后只能摸切、和牌或合法开杠；三种杠都允许。杠后仍须满足报听条件，原文没有“听口必须完全不变”的要求。
- 自摸的实际和牌张须至少3点，点和的实际和牌张须至少6点。已满足条件时有和必和；多家可和同一张弃牌时，距放铳家最近的下家取得和牌权。
- 过碰同一牌后，至本人下一次摸牌前不能再碰该牌。碰后未摸牌不能立即开杠。最后一张正常摸牌及其弃牌不能再开杠。
- 杠后从牌尾最后一墩先上后下补牌。保留七个完整墩：尾墩完整时保留14张，尾墩已取上张时保留15张；禁止没有合法补牌的杠。

## 计分

和牌基本分＝番种分＋实际和牌张点数。没有指数翻倍、额外底分或其他规则的番。

| 番种 | 分值 | 解释 |
| --- | ---: | --- |
| 平和 | 0 | 普通四组面子加一对将 |
| 一条龙 | 20 | 同一花色的123、456、789三组顺子 |
| 清一色 | 20 | 全部牌属于原书四种花色之一 |
| 七对 | 20 | 七对；四张相同牌可计两对 |
| 豪华七对 | 40 | 七对且本次和牌张恰好形成第四张同牌；已有其他四张不算豪华 |
| 十三幺 | 60 | 六种数牌幺九和七种风牌各一张，再加其中一对 |

只有清一色可以与另一番种复合，其他番种取最高项。例：清一色一条龙和九万，基本分为20＋20＋9＝49分。

明杠、加杠每家支付该牌点数，暗杠每家支付两倍该牌点数。所有杠账推迟至有人和牌后统一结算；流局全部取消。

点和时三家均支付和牌基本分。庄家和牌，三家各再付5分；闲家和庄家弃牌，庄家多付5分；闲家和另一闲家的弃牌，庄家不额外付5分。自摸按对应关系整体乘二。

未报听者放铳时，由该放铳家支付所有和牌款，以及全桌其他人的杠款；其自己的杠款取消。每个其他杠家的杠款按三家应付合计，由该放铳家一人承担。

原书第10页例：庄家A明杠三万，B暗杠二筒，C明杠九筒；未报听的B放铳给A，A和牌基本分7分，最终四家变化为 `A +45、B -72、C +27、D 0`。

## 实现分层

服务端牌形、报听资格、点数与支付规则放在 `game_calculation/shanxi`；`game_shanxi/ShanxiGameState.py` 复用现有回合制权威询问、动作、断线重连、观战和牌谱执行器，只重写山西规则的钩子。机器人只读取本手和可知牌。

客户端由规则清单注册大厅与听牌提示。普通动作协议增加可选 `concealed_discard` 和 `tile_count`，前者区分删手牌所需的真实身份与暗扣河牌，后者同步七墩保留随补牌变化后的实际可摸余张。旧规则未提供字段时保留原有行为。

Unity 与 Web 已接入此规则。具体编译、实机、网络和回放验证结果见对应开发任务的验证记录；本说明不表示已部署到公共服务。

## 听牌提示

提示先按基本牌形列出听口，不因基本条件不足隐藏听牌。达到点和点数时显示报听后的和牌基本分；三至五点的听口在同手存在六点以上听口时显示“仅自摸”。和牌张不足三点，未达到最低起和点数，显示“未起和”；三至五点听口若整手没有六点以上听口、不能满足规则明确要求的基本报听条件，显示“未满足”。

基本分按报听后估算，不包含庄家差额或全桌杠账，不另模拟过水及偶然条件。可知余张独立显示，耗尽的牌仍保留在提示中。对局、切牌预览和牌谱采用相同的基本提示判断；本人暗扣过的报听牌计入本视角已知张数，其他家的暗扣身份不公开。Web 山西回放使用山西基本分及“分”单位，不套用国标番数。
