# 长沙麻将经典双鸟规则

- 使用万、筒、条 1-9，共 108 张牌。
- 允许吃上家牌，允许碰、杠和抢杠胡。
- 小胡要求 4 组面子和 258 将；经典基础分保持小胡 1/2、大胡 6/7。
- 创建房间可开启卡摸，开启后标准小胡只能自摸，所有现有大胡仍可接炮；默认关闭。
- 两种计分模式均可选择不封顶、大胡数量封顶或最终分值封顶，可选常用档位或在创建房间时自定义，开局后固定。大胡数量先封顶再算鸟，分值在鸟之后封顶。
- 封顶按每个付款方分别计算；同一开杠批次中同一付款方给同一赢家的多张胡牌累计后封顶，不同赢家分别封顶。起手胡不受任何封顶限制。
- 开杠张数只可选2或4。每次明杠、暗杠、加杠重新掷两个骰子，从牌墙尾部第1墩向前数，优先取骰子和数对应的墩，开4张还取下一墩。
- 起始墩不存在时改按较小骰子的点数定位；小点数仍越界则开出0张。定位到的墩存在时拿实际牌张，后续墩不足不再回退，半墩也算一墩。牌墙最后一张海底牌始终跳过。
- 开出0张仍视为杠成立且锁手，不补牌也不再出牌，直接下家继续摸打；仅剩海底时进入下家的海底流程。补张仍按原流程补一张，不掷骰子、不锁手。
- 大胡支持碰碰胡、将将胡、清一色、全求人、七小对、豪华七小对，以及天胡、地胡、海底、杠上开花、杠上炮、抢杠胡等情境牌型。
- 扎鸟张数可选 0、1、2、4，可选择从本局开始庄座位 0 或胡牌玩家起算。
- 海底牌先盖放在桌面中央。玩家选择后翻开并进入该玩家牌河；该玩家能胡时按海底自摸结算，否则视为打出海底牌，只允许其他玩家荣和或跳过。
- 开杠补牌先逐张判断本家自摸；多张可胡时手牌牌型只计算一次，并按可胡张数累计杠上开花。本家可选择和牌或跳过，但不能修改原手牌。
- 本家不能和或主动跳过时，再收集每张补牌上的全部他家荣和。同一张允许一炮多响，同一赢家胡不同补牌时分别计分，整批共用一次扎鸟；不分庄闲计分时以开杠者作为本批鸟起点。
- 本家跳过杠上开花后，整批合并基础分作为过手阈值；紧接的强制摸切不清除该限制，直到该玩家下一次实际摸牌，自摸始终不受过手限制。
- 无人和牌后才判断本家暗杠；本家可选择任一成立的暗杠，其他补牌先摸切且不再开放他家响应。
- 本家不暗杠时，其他玩家鸣牌按杠、碰、吃和座次确定唯一动作。玩家开杠后锁手至本局结束，后续普通摸牌只能自摸、暗杠或摸切刚摸到的牌。
- 吃、碰、明杠统一使用 `cut_from_player` 和 `cut_tile` 标识被认领的弃牌来源和牌值。
- 起手胡支持四喜、板板胡、缺一色、六六顺和三同，具体类型可以在创建房间时开关。
- 四喜只亮出命中的四张牌，六六顺只亮出对应两个刻子的六张牌，三同只亮出三门同点数对子共六张牌。
- 同时命中多个固定子集牌型时合并所需牌张；板板胡或缺一色无法用固定子集完整表达，因此仍亮出整手牌。
