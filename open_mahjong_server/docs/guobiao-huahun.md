# 国标（花混癞子）

本站四人娱乐子规则 `guobiao/huahun`，建房选项排列在四癞子之前。未另行说明的动作、国标番种排除关系和支付规则沿用标准国标。

## 牌张与行牌

- 牌山固定144张：136张常规牌，春夏秋冬（51–54）各一张作为癞子，梅兰竹菊（55–58）各一张作为补花牌。不额外加入四癞子场的59号红花。
- 每张癞子在和牌时可替代任一常规牌；替代后连同副露，同种常规牌最多四张。未花杠时支持国标基本和型及特殊和型，取全部合法替代和拆分中的最高番。
- 癞子留手不补花、不计花分。仅刚摸到的癞子可以当次摸切；起手和已经留手的癞子不能手切。碰吃后也不能打出留手癞子。其他玩家不能对打出的癞子吃、碰、杠或点和。
- 四张季节癞子齐全时可主动花杠，公开四张后补摸一张。花杠占一副，剩余手牌与其他副露须组成三副一将；不能以七对等特殊和型替代。和牌时另计“花杠”88番，可复合余牌和和牌方式符合的其他番种，不重复计普通暗杠或四杠。花杠本身不即时收分。

## 起和与结算顺序

| 和牌使用的癞子数 | 最低牌型番 |
| --- | --- |
| 0或1 | 8 |
| 2 | 16 |
| 3 | 32 |
| 4 | 64 |

自摸癞子计入数量；已经花杠的四张仍计入使用数。先以牌型番判断起和，黑花分及无癞子奖励均不参与门槛。花杠88番属于牌型番，仍须手牌真正成和。

达到门槛后，先加黑花分，再计算无癞子奖励：

- **无癞子奖励为三项下拉列表**，依次为“无癞子+8分”（默认）、“无癞子翻倍”、“不额外加分”。加8方案为 `F=牌型番+黑花分+8`；翻倍方案为 `F=2×(牌型番+黑花分)`；不额外加分为 `F=牌型番+黑花分`。持癞子或已经花杠均不享受此奖励。
- **黑花递增计分默认开启**：1、2、3、4朵合计4、8、16、32番。关闭时每朵1番。
- 有癞子时，结算番 `F=牌型番+黑花分`。花杠88番已包含在牌型番中。
- 国标支付底分8不变：自摸三家各付 `8+F`；点和放铳家付 `8+F`，另两家各付8。

例如无癞子牌型8番、黑花2朵：默认结算为 `8+8+8=24番`；选择翻倍为 `2×(8+8)=32番`；选择不额外加分为 `8+8=16番`。牌型只有7番时，即使有花分或无癞子奖励，也不能和牌。2张癞子牌型15番同样不能靠花分达到16番。

## 独听与和绝张

“癞子多面听”默认关闭。先固定每张癞子代表的常规牌，再从完整和牌中移除和牌张，检查该确定牌形的全部合法听口；符合唯一听口才允许计单钓将、嵌张或边张。独听仍遵守国标排除关系，也能在牌型原有7番时补足8番。不得省略应计的独听番以取得无番和。

开启开关后，持癞子的多面听均不计独听；没有癞子的牌不受影响。全求人按四副明露及点和将牌判断。

和绝张只按实际和牌张判断：摸到春夏秋冬癞子不计和绝张，即便它替代的常规牌已经在场上出现三张。只有和到真正的常规牌，且此前场上已见该牌三张时，才计和绝张4番；手里持有其他癞子不影响这项判定。本条仅适用于花混子规则，不调整普通国标或四癞子场的既有判定。

## 房间、牌谱与性能

支持1–4圈四人自定义房，独立统计为“国标（花混癞子）”；不进入排位、自动匹配或普通复式牌墙。建房固定上述分档门槛，不接受普通起和番覆盖。奖励方式、黑花开关及独听开关随重连和牌谱保存。

结构求解复用四癞子缓存，将四种季节牌规范化为同一种求解符号，物理牌限制在入口校验。机器人用结构听牌及距离选择打牌，服务器仅为真实和牌候选精确计番，使用既有进程池。用户展开的提示由客户端本地计算，求解与计番缓存均有上限。规则适配遵守[客户端提示计算边界](local-client-hints.md)。
