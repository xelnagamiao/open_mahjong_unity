# 广东麻将 · 推倒和（MIL 2024，无癞子）

本平台底本为存档《推倒和麻将（推广）竞赛规则（试行2024版）》，由国际麻将联盟（MIL）规则委员会审定。采用正文无万能牌标准本，不启用第十五页地方补充规则。

- 原始资料：`other/rule/MIL_rule/推倒和麻将（推广）竞赛规则（试行2024版）.pdf`，共16页。
- 主规则：`guangdong`；子规则：`guangdong/tuidao_mil2024`；细则版本：`mil-tuidao-2024-om1`。
- 大厅归类为「广东麻将 → 推倒和（MIL 2024，无癞子）」。[麻将运动技术等级评定中心的介绍](https://www.mahjonget.com/official.html)将推倒和列为广东麻将的常见变种；本平台据此作入口归类。这里的计分与动作底本仍为独立的 MIL 推倒和2024文件。
- 广东地方玩法并不只有一个版本，例如[JJ官方广东推倒胡说明](https://www.jj.cn/news/320/20111025103000019369.shtml)采用禁吃、主要自摸及买马等规定，与本底本不同。平台不以该地方版本替换 MIL 正文；含鬼牌的 [MIL 广东2023版](../guangdong/README.md)是同一大类下的另一个独立子规则。

## 牌张、流程与报听

使用万、筒、条及七种字牌，每种四张，共136张，无花、无癞子。十三张手牌，庄家起手十四张；普通和牌为四组面子与一对将，另支持七对、全不靠、十三幺。未开杠的四张同牌可以当两对。

可吃上家，可碰杠三家。和牌优先于碰杠，碰杠优先于吃；同一张牌多人和时按行牌方向取最近一家（截和）。每次弃牌、抢杠回应最长三秒，也受房间剩余行动时间约束。

报听是可选的二番和种，不是和牌门槛。只能在摸牌后、打出一张牌之前声明。报听后锁定手牌，只能打出新摸牌；不可吃碰，杠不得改变声明时的听口与牌形。吃碰后只允许打牌，不允许立即暗杠、加杠或报听。

杠后从牌墙末端补牌。加杠开放抢杠和；暗杠、大明杠不开放抢杠。正文把加杠视作可被碰、杠、和的打出牌，但本标准本每种牌只有四张，原碰牌已经占三张，其他人不可能再持对子或暗刻，因此没有可执行的抢加杠碰、杠分支。

牌墙余六墩即荒庄，末端孤张不计墩数：剩12或13张均不可继续摸牌。最后可摸的牌打出后仍可和牌，之后荒庄；此时不再吃、碰、杠。海底只用于最后弃牌的点和，最后一摸自摸不自动加海底。

庄家和牌连庄，闲家和牌由下一位庄家接庄。原书第三节不按风圈计算常规比赛，以规定副数或时间结束；平台提供4、8、12、16局，每一副均计入总局数。

## 二十三种番种

| 番数 | 番种 |
| --- | --- |
| 2 | 门清、平和、断幺、报听 |
| 6 | 碰碰和、全带幺、大吊车、混一色 |
| 8 | 抢杠、海底、杠上开花、全不靠、清龙 |
| 16 | 天听、七对、清一色 |
| 24 | 豪华七对 |
| 32 | 天和、十三幺、大三元、字一色、四暗刻、大四喜 |

番种定义以原书第八至九页为准。需要注意：

- 平和须四顺子、序数牌将；不要求门清。
- 清龙须同一花色的123、456、789三组顺子。
- 全不靠为三门分别分配147、258、369所得九张序数牌，与七张字牌构成的16种牌中，取任意14张不重复牌。无需九张数牌或七张字牌全部齐全。
- 豪华七对有至少一组四张同牌；未开杠的四张按两对处理，不按四副相同刻子的其他地方定义处理。
- 天和包含场上无吃碰杠时各家第一次摸牌自摸；天听要求场上无吃碰杠时第一次摸牌即声明，之后和牌。
- 四暗刻须四组暗刻或暗杠；点和只可补成将牌，不能把点和补成的刻子计为暗刻。

除必然包含的番种外可以相加，最多32番。天听不再加报听；豪华七对不再加七对；特殊和形与天和不重复计门清；四暗刻不重复计门清、碰碰和；大四喜不重复计碰碰和；字一色不重复计全带幺。多个拆分取有效番数最高者。

## 支付与过水

基本分为「2＋封顶后的番数」。自摸时三家各付一份基本分；点和、抢杠和由放铳者或被抢杠者付两份，另外两家不付和牌分。

| 杠的来源 | 即时支付 |
| --- | --- |
| 大明杠 | 点杠者付2分 |
| 用新摸牌加杠 | 其余三家各付1分 |
| 用原手牌加杠 | 不计杠分 |
| 暗杠 | 其余三家各付2分 |

加杠在抢杠窗口关闭且杠成立后才计分。被抢杠时恢复原碰牌，被抢的第四张归和牌者，不收杠分。荒庄保留已经成立的杠分，不追加查叫、退税或买马。

放过可点和牌张，或本人打出了自己的和牌张后，直至下次摸牌或碰牌后处于非和牌型之前，不得再点和番数不高于该次放过的牌。更高番仍可点和；吃碰与摸牌后的自摸不因此被禁止。番数以32番封顶后的值比较。仅取消一次自摸按钮，不把自摸专属的番种计入过水门槛；若实际打出和牌张，则重新按点和条件记录门槛。

## 平台补则与实现边界

1. 原书明确庄和连庄、闲和轮庄，未明确荒庄后的庄位。本版本规定荒庄连庄，局数照计。
2. 报听后合法暗杠须使用新摸牌补成原暗刻，听口相同且原先任何有效拆分不得依靠该牌组成顺子或特殊和形。大明杠也检查相同的牌形保留条件；加杠须保留听口。候选目标由服务端逐张下发，客户端不会把所有四张同牌一概作为可杠目标。
3. 数字版本用动作按钮、公开报听标记、固定摸牌位替代线下报声与听牌卡。无需依赖语音识别；配音复用同音源的“报听”声明，与原书口头用词“听”语义相同，规则判定以按钮与服务端记录为准。
4. 结算时公开所有手牌、暗杠，供同桌核对；重连恢复公开声明、锁手、杠分和终局结果。局中其他玩家的手牌、暗杠按项目统一隐藏规则处理。
5. 原书的触牌、拿牌越界、误报后罚分、裁判仲裁等线下程序不伪造为在线动作。服务端拒绝非法吃碰杠、诈听和诈和请求；有效动作顺序、计分和牌张来源写入牌谱。
6. 房间可以设置局数、局时、步时、提示、密码、游客限制、观战等平台选项。规则本身固定，无花、无鬼牌、32番封顶；不提供偷偷改变正文的地方馆规开关。

源码位于 `open_mahjong_server/server/game_calculation/tuidao`、`server/gamestate/game_tuidao` 与 `server/room/tuidao_room.py`。沿用既有回合执行器、动作窗口与生命周期，计番、合法杠、过水、庄位和支付由推倒和模块负责。
