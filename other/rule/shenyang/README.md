# 沈阳麻将（MIL 2025）

底本为本目录《沈阳麻将（推广）竞赛规则（试行2025版）》；平台规则标识为 `shenyang/mil2025`，实现版本 `mil-shenyang-2025-om1`。

使用136张牌。基本和牌须有幺九、有刻子或杠（箭牌将可替代）、三门齐全或清一色；七对不受这些条件限制。先碰或明杠开门后才能吃上家的牌，闭门可报听。报听后可在保持听牌的前提下暗杠或直杠，不要求听口不变；不能加杠、喜杠或旋风杠。

喜杠为中发白各一张，不补牌；旋风杠为四风各一张，补一张。两者保留闭门。杠后补牌可以选择公示过蛋，筒子三家各付5分，一条各付10分；不公示不计分。过蛋即时记分，流局保留。番种依规则书25项计算，六番封顶，庄与闭门因素逐个付款者计算。点和由放铳一家支付，自摸三家支付，允许截和。

最后四张依序分张，只能自摸或过，不出牌、不再杠。过牌暗扣至本副结束。和牌者下副坐庄，流局庄家不变并使下一副长毛；首四打相同且此前无吃碰杠或报听也触发长毛。线上局时、步时和对局副数由房间配置决定，线下裁判处罚不由自动规则推断。

提示采用平台统一优先级：未满足、未起和、仅自摸、合法和牌点数。本规则没有最低番门槛，结构成立但不满足基本条件显示“未满足”；顺和限制、分张或中发白第四组限制显示“仅自摸”；合法点和显示逐家最低至最高点数以及自摸总收入。基础对局统计包含过蛋与终局分差；暂不提供番种分布统计。特殊杠完全来自手牌并保留闭门，按现有统计口径不计吃碰明杠副露局数。

待复核疑点：第7页称分张前最后一摸“必须打出一张牌”，第9页一般和牌条款允许摸到和牌型时和牌。经用户确认，平台允许该摸自摸和牌；未和必须出牌，禁止继续加杠、暗杠。后续如权威解释变化，应同步修改这条规则及测试。

相邻边界：牌墙剩四张、尚未开始分张时，原文没有明确最后弃牌的吃、碰和特殊杠。经用户确认，允许吃、碰及不补牌的喜杠，禁止需补牌的点杠、旋风杠，以保留四张供分张。开始分张后仍只允许自摸或放弃。此解释与上一项一起保留供二次核对。
