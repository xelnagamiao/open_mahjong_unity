# 十六张 · 规则材料摘要

十三张仍是全球主干。十六张是局部加一搭：闲家 16、庄 17，和形五搭一对。[wiki-16]

## 福州开金

144 张，补花后开金。金是替子。抢金发生在开局第一圈：庄家打出首张再换金，或闲家摸进金。三金倒：凑齐三张金即可和，不必常规牌型。金雀：将是金。[wiki-zh-fuzhou][zingzeu-fz][baike-fuzhou]

金能替什么，来源不一：福州话资源网写可代替字牌组成雀或顺；18183 等写可替代任意牌。并列，不选边。

## 台湾台制

按台计分，精髓是连庄拉庄（连 N 拉 N + 庄 = 2N+1 台）。常见 16 台制，也有 24 台制。自摸三家付，放铳一家付。[wiki-tw][wikibooks-tw]

桌上约 1950s–70s 定型。1980 年到现在并没有冻住。

南北差是桌上并行，不是后起发明。北部有花（144）、边张／中洞／单吊有台、满台常无上限、庄家台加连拉。南部通常无花（136）、边嵌单常无台、不计庄家台只计连几拉几。[wikibooks-tw][eastking-ns]

2001 年鈊象《明星三缺一》把一套口传台数写成电脑规则，胡牌时逐条列出；这是定型层，不是新发明十六张。[taiwan-md-mingxing] 2002 年中华麻将竞技协会立案，是竞技社团，不是把南北桌规收成一种。[atawmj-2002]

来路两说，都还没有民初规则书：

- 维基 / 简而清 / 关兆豪：福建十六张入台。[wiki-tw][zj-taiwan]
- 台湾麻将协会：广东十三张演成台制。[atawmj-origin]

谱系边标争议，不画成已证父子。

## 港式十六张

HKMA 称港式台牌、台湾牌（仅限香港本地称呼）。糅合港麻、正宗台湾麻雀、日本麻将及国标。关兆豪：港式台湾牌与台湾当地颇不相同；新章和种从十三张新章传入，不是台制起源。[hkma-16][zj-taiwan]

总例在 hongkong 档案，本档只做指针。

温州也是十六张，但核心是翻财神，细则见 jiangnan-caishen。扬州江都记符十六张只作线索。
