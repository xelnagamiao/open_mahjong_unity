# 数据中心的数据边界

数据中心只读取当前 Web 应用数据库内已成功保存的牌谱和必要的逐玩家指标。数据库副本的下载与恢复是独立环境维护操作，管理页面不提供此类功能。

新实现以 `anti_cheat_center` schema 中的逐场缓存、关系贡献、证据和统计表为数据源，详情见 `anti-cheat-center.md`。所有计算必须由明确的更新请求启动；查询和服务启动不会发起分析。

原有无时区 `created_at` 按本项目已确认的北京时间存储语义转换，内部使用带时区时间。输入指纹也包含时间和关键参与者指标，防止历史修正漏算。统计页面的数据更新时间表示该统计版本的观察时间，不承诺包括此后提交的牌谱。

规则不支持、记录不完整、机会计算不足、净分单位不明等状态分别记录，不能解释成零次异常。原始数据保持只读，派生数据写入独立 schema；证据接口要求原有管理员身份且按页返回。
