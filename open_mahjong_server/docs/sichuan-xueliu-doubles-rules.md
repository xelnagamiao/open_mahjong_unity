# 血流双打 · 随机单桌 2V2

子规则：`sichuan/xueliu_doubles`。规则快照版本：`xueliu-single-table-2v2-v2`。
这是四人同桌、两人一队的独立子规则，继续沿用平台换三张血流的 108 张牌、十三张手牌、连续胡牌和牌谱协议。

## 实现范围

- 用户 2026-10-09 提供的聊天：可控猪；东南、南西、西北、北东依副序先换；与对家队友交换；队友之间胡、杠不转分。
- 本子规则采用随机单桌、队伍同分加副。两桌同牌的复式赛制使用独立子规则 `sichuan/xueliu_doubles_duplicate`。

开局天胡、胡后锁手、过和、杠后续摸、庄家和计时细节，采用平台换三张血流行为及下述明确的胡后杠牌条件。首次胡前维持原过和限制；过队友的胡不新增过和限制；胡后对手必胡不受旧过和上限拦截。自摸仍可选择胡或继续合法操作。

## 房间、座位与交换

房间保持原四列玩家卡片、配置区、底部按钮布局。分队使用卡片内的 A/B 选择，不增加房间注释、随机分队功能或右侧双打规则说明行。必须四人、每队两人才能开始；队伍变更使准备失效；旧阵容版本不能准备或开始；开局后锁队。机器人按座位而非用户 ID 区分。

服务端洗座时随机决定两队方位与队内座次，并保证队友对坐。开局后的座位编号 0/1/2/3 对应东/南/西/北，换牌顺序以副序而非庄家变化计算：

| 副序模 4 | 第一阶段 | 第二阶段 |
| --- | --- | --- |
| 1 | 东、南 | 西、北 |
| 2 | 南、西 | 北、东 |
| 3 | 西、北 | 东、南 |
| 0 | 北、东 | 南、西 |

每人从自己的原始手牌选三张同花牌。当前组的两家中心盘同时持续闪烁，一人提交后仍保留两处闪烁，直到两人全部提交或超时。服务端随后关闭所有选牌权限，广播这两家各三张牌飞向对家的动画，等待 1.4 秒后才开启下一组选牌及闪烁。第二组完成后同样播放交换动画，再同步最终手牌并进入定缺。四组顺序均按副序轮换。

动画和第二组选牌期间仅向接收视角显示本队的花色，其他交换牌显示背面，不显示数字、对手花色或队友暗手。第二组选牌时保留队友送来的三张花色牌以便辨认。四人全部选完后才在服务端统一与对家互换，不能把尚未收到的牌再次换出。动画中重连补发剩余动画时间及无操作权限的状态。

每阶段使用独立倒计时 `max(step_time, 10)`；掉线/机器人由服务端选牌，超时同样补齐。先手全部完成并发出后手提示后，后手自动选牌等待 3 秒；两名机器人并行等待，不随房间机器人速度缩短。真人后手收到提示即可选择。后手自动选择尽量避开队友送来的花色。重连恢复当前阶段、剩余时间、本人是否已提交和合法操作；不重新选已经交出的牌。

## 行牌与计分

碰后、出牌前允许加杠，既可以加刚碰的刻子，也可以加原有刻子；须有补牌且不能是定缺花色。加杠仍可被抢，无人抢杠时补牌；被抢则恢复原碰并退回本次杠分。

换牌后四家独立、同时定缺，全部确认后同时展示四张定缺卡，从屏幕中心飞到各家头像原有的定缺位置，完成后才开始出牌计时。分组仅适用于换三张。可保留定缺牌并打其他花色，但定缺牌仍不得碰杠、不能带定缺胡牌。胡后普通出牌只能摸切，不能碰，允许明杠；暗杠、加杠只能使用本次摸到的牌。三种杠统一要求杠后的听牌集合包含本人本局此前所有实际胡过的牌（重复张按集合处理），未胡过的听牌不必保留。杠后更新实际听牌，后续胡牌张继续加入约束。连续胡牌直到牌墙摸完；同队两人先胡不会提前结束。

队伍蓝/红色直接使用玩家 ID 下的原有底板，不额外显示队伍方块，也不占用定缺卡位置。换牌动画的起点、汇合点和终点以中心盘四边标记的实际投影为基准，随中心盘位置和画面缩放调整。续打快照只校正手牌内容差异；内容不变时保留本家手动顺序、拖拽状态和原有牌对象。

胡、抢杠、自摸、杠分和流局赔付均只在异队玩家间转移。允许胡队友的牌并进入/维持胡后锁手状态，但队友之间分变为零，该和牌张同样加入后续杠牌必须保留的集合。胡过后，对手点炮或被抢杠由服务端直接胡牌，不弹选择、不等待点击或超时，真人、机器人、断线玩家一致；一炮多响仍等待其他可选玩家分别响应。队友点炮可过，也可选择满足上述条件的明杠。

| 项目 | 新子规则 |
| --- | --- |
| 基本胡 / 碰碰胡 / 七对 / 清一色 | 2 / 4 / 6 / 6 |
| 金钩钓 / 清碰 / 清七对 / 清金钩钓 | 8 / 10 / 12 / 16 |
| 门清、断幺九 | 各加 1；七对不加门清 |
| 胡牌支付额 | 番值 × (1 + 实体根数 + 情境根数) |
| 暗杠 | 两名对手各付 2，总收 4 |
| 补杠 | 两名对手各付 1，总收 2 |
| 直杠 | 点杠对手付 2；队友点杠为 0 |
| 查叫 | 未听者付每名已听对手理论最大胡分 |
| 花猪 | 每名已听对手收 `max(32, 2 × 该对手理论最大胡分)` |

杠上花、杠上炮、抢杠和海底自摸各增加情境根；不增加海底点炮。即时杠分与根倍率分开记录。抢杠退回当次补杠，退分幂等；流局不另外退历史杠分。没有已听对手时不发生查叫/花猪转账。

每副两名队员分数相加，逐副记录队伍变化；盘末以队伍累计分判胜。设定副数结束时同分则加副，继续顺序换牌，直到分出胜负。此规则不使用 SBR 双打的追平队判胜法，也不进入现有单人血流天梯。

## 协议和隔离

沿用 `team_by_seat`、`roster_revision`、`sichuan_teams`、`doubles_result`；新增手牌询问字段 `xueliu_exchange`：`stage`、`active_players`、`selection_done`、`teammate_suit`。未轮到玩家的动作列表为空。重连与正常询问调用同一私密视图构造方法。

牌谱保存完整子规则快照、四人队伍、交换方向/分组、实际换出牌、定缺和逐副队分。完整牌谱在终局后提供；实时快照仍只有本人的暗手。Unity 与 Web 按新子规则识别血流回放，避免将胡牌玩家按血战退场。

`is_team_game` 仅控制共同分队和展示；`is_doubles` 保留 SBR 专用含义。因此 SBR 双打的不定缺、同队先和结束与花猪规则不会混入血流。
