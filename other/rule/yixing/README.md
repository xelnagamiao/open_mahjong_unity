# 宜兴麻将规则资料

平台宜兴规则族为 `yixing`，子规则为 `yixing/standard`。规则版本为 `yixing-user-20261002-om2`。

当前底本为用户于 2026 年 10 月 2 日提供的《宜兴麻将规则.doc》。`yixing-rulebook.doc` 和 `yixing-rulebook.docx` 保存最新正文；按用户要求，花牌条款为：

> 花牌：春、夏、秋、冬、梅、兰、竹、菊，抓到花牌必须补牌，花牌补牌不算杠开，胡牌时每张花牌计1花。补花和杠从牌山后摸

`yixing-rulebook-20261002-initial.doc` 是首次收到的旧版底本，保留供追溯，不作为平台当前规则。此规则是用户提供的地方玩法，不标注为 MIL 或香港麻雀协会规则。

规则书阅读页为 `/rulebooks/yixing.html`，提供原文。DOC、DOCX 与 PDF 提供同一版正文。
