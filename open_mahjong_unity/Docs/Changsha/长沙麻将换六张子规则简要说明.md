# 长沙麻将(换六张)

待发布说明，用于创建房间的子规则说明。

108张数牌，四家先各选六张，最多两种花色，再掷双骰统一交换。每小局重新掷抓牌骰子指定一家禁终局小胡，四喜照常收分。固定杠摇四张、补张一张、两只鸟。小胡2分，单大8分，每多一大翻倍；同牌型杠胡合并，不同牌型分别算后相加。支持报听、明牌、闷杠与一炮多响。

选牌时间10至60秒，默认30秒，超时自动选牌。提示、放大的确认按钮和骰子显示在自己手牌上方。

开局2秒内任意一人点"不换"，全桌跳过换牌；无人点击则换第一轮。四家看到换后的手牌后，有2秒选择"再换一轮／不换了"，最先有效提交者决定，超时不换。第二轮仍先选六张再掷新双骰，最多两轮。
