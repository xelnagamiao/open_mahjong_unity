# 反作弊数据中心

页面 `/admin/anti-cheat` 读取已发布统计。只有点击“更新数据”创建增量任务；服务启动、打开页面、筛选和刷新均不启动分析，也没有定时扫描。数据库副本的准备是独立的环境维护操作。

## 数据范围

数据中心只统计已保存的四人国标标准段位场，排除其它规则、赛事、娱乐及三人模式。旧混合范围统计不作为当前榜单；范围迁移通过显式更新发布。

## 两种递送口径

在玩家 A 与 B 的共同牌局集合中：

- A 喂 B 的递送率 = A 给 B 的事件数 / A 给三个对手的总事件数。
- A 从 B 收牌的递送率 = B 给 A 的事件数 / 三个对手给 A 的总事件数。
- 同桌率 = A 与 B 的共同场数 / A 在所选规则和时间窗口的总场数。它显示关系覆盖程度，独立于出现概率。

喂牌和收牌两侧各自展示全口径与和牌递送率。每种口径分别展示对应代表伙伴的出现概率，喂牌和收牌两侧各有全口径、和牌两列概率。同桌率独立显示为“百分比＋共同场数 / 玩家总场数”，对应全口径的代表伙伴。全口径计入吃、碰、弃牌明杠及普通点和。和牌口径的分子和分母都只计普通点和。双方的共同牌局相同，喂牌和收牌分母按各自方向计算。不同伙伴涉及不同共同牌局集合，伙伴行不能简单相加。

统计基准固定为三分之一。令 k 为对应事件数、n 为该方向的总次数，X ~ Binomial(n, 1/3)：

```
p = P(X ≥ k)
出现概率 = 100 × p
```

出现概率为均分、独立事件假设下达到当前次数或更多的概率，直接显示 p，不做 1−p 转换。p≤5%标红，极小值使用科学计数或带上限的显示，避免舍入成绝对0%。同桌率不改变 p；没有最低场数、跨日数或事件数门槛。

NIST 下限已从页面、生成统计、排名索引及公开筛选参数中移除。n=0时出现概率为空；4/4的出现概率为1.2346%，10/10为0.0016935%。

这是固定均分假设下的单关系筛选指标，不是作弊概率，也没有对全平台重复比较作显著性校正。吃牌座次限制、事件相关和正常打法差异均可能产生偏离，应结合牌谱理解。固定基准不拟合个人均值。

## 事件与展示

ALL包括吃、碰、弃牌明杠及普通点和；MELD只含前三类；RON只含普通点和。自摸、暗杠、补杠不重复产生他人来源，特殊来源排除。这里只统计已验证来源的实际事件，结构向听改善等辅助特征不代替事件计数。每场需要完整四人、12个有向关系和一致的三来源总数，防止缺失事实抬高比例。

排行榜以玩家为单位。默认左右分别取全口径实际递送率最高的伙伴，按两侧较大的实际比例降序；展开后同样按每个伙伴的较高方向排序。并列以事件量和稳定ID排序。每个口径、每个方向独立挑选代表伙伴，可能指向不同的人；显示的递送率、概率和同桌率均属于该代表关系。默认全部规则先合并次数再计算，绝不取各规则最大值当作全局比例。

## 筛选与排序

筛选、排序直接从对应列的表头进入，玩家表头包含昵称/ID与时间窗口，伙伴表头包含规则。指标表头确定口径、方向和指标，可设置范围、升降序或选择喂收两侧。出现概率以较小值代表更强偏离，其余指标以较大值选取代表；切换升降序只改变榜单顺序，不改成挑选最弱关系。

可对递送率、同桌率、出现概率设置包含端点的百分比范围。全口径与和牌的喂/收出现概率表头均提供“筛选异常用户”，默认上限5%，也可输入0至100%的自定义上限。自定义上限不会再叠加固定5%限制。数值范围与异常条件须由同一口径、同一伙伴、同一方向满足。筛选在全部已发布关系上执行，再选代表、排序和分页，避免只检索当前页，或被原来的最高递送率关系遮蔽其它符合条件的关系。其它显示口径保留自身代表，不受当前口径条件误删。

没有事件的指标显示为空，数值筛选不匹配空值；不设筛选时仍保留这些玩家，空值在升降序中都排最后。没有最低场数或事件数门槛。筛选、排序和展开仅查询已发布统计，不读取牌谱、不触发更新任务。

## 罗伯特复核

玩家展开后，针对具体伙伴的喂牌或收牌方向手动点击“罗伯特复核”，再选择全口径或和牌并开始。收牌方向交换弃牌者与接收者。只有明确开始才创建任务；打开抽屉、切换口径不启动计算。活跃任务可查看进度和取消，任务查询不重新计算。

复核仅覆盖国标段位场。机器人只获得弃牌者当时可见的信息；结果是与机器人参考的比较，不代表作弊结论。

- 喂牌偏离率 = 指定口径喂给目标的弃牌中，明显差于机器人参考的次数 / 可比较的对应弃牌次数。
- 常规出牌偏离率 = 在同批同桌牌局中排除喂给目标的**全部**弃牌后，其余弃牌中明显差于参考的次数 / 可比较的其余弃牌次数。
- 偏离率差按“喂牌偏离率 − 常规出牌偏离率”计算，以百分点显示。喂牌偏高的出现概率取单侧 Fisher 精确检验的上尾，固定两组样本量和偏离总数，两组偏离机会相同时，计算喂牌组至少出现当前偏离次数的概率。此值按弃牌逐次比较，未校正同局相关性或多伙伴筛选。任一组分母为零时，差值和概率均显示为空。
- 无法比较的弃牌、牌局及无法重建的小局单独报告，缺失记录不作为零分；没有可比较记录时比例显示为空。

按每次决策的优先层比较差值，达到该层阈值才算明显偏离。向听阈值为整数，页面其余阈值可输入两位小数；服务端接受范围内有限小数。进张与重塑值为加权量，不要求本身是整数。

| 阈值 | 默认 | 页面范围 | 单位 |
| --- | ---: | ---: | --- |
| 向听差 | 1 | 1–8 | 向听数 |
| 足番一摸进张差 | 4 | 1–136 | 加权张数 |
| 普通进张差 | 4 | 1–136 | 加权张数 |
| 番数差 | 8 | 1–1000 | 番 |
| 荣和进张差 | 4 | 1–136 | 张数 |
| 重塑差 | 24 | 1–20000 | 加权重塑分 |

复核使用 `POST /anti-cheat/robert-reviews` 开始、`GET /anti-cheat/robert-reviews/:id` 查询、`POST /anti-cheat/robert-reviews/:id/cancel` 取消。阈值随任务提交，结果同时保留两项比例的分子与分母。

## 存储与增量

原始牌谱只读，派生数据保存在 PostgreSQL 的 `anti_cheat_center` schema。

- `games`、`pairs`、`evidence` 保存逐场事实和来源事件。只为新增或内容变化的牌谱提取特征，已有事实直接复用。
- `dirty_games` 保留变化前后参与者；受影响关系、双方汇总及移出窗口的贡献在显式更新中重算。
- `directionalStatistics.js` 实现固定基准和双向分母；`populationPipeline.js` 作为现有入口仅执行新的方向聚合，不再训练群体模型或预测得点。
- `pairs_versions`、`players_versions` 保存版本区间，发布事务原子切换代际。模型迁移结束旧预测版本，普通增量保留未变化统计。
- `player_rank_profiles` 按玩家、规则和窗口保存各项指标的代表伙伴。显式更新时与统计一起提交，只替换受影响玩家的记录。打开普通榜单可按这些代表排序，设置数值范围时再查满足条件的伙伴。旧版统计没有这份索引时仍可浏览。
- `__ALL__` 保存跨规则汇总，实际规则另存；API默认仅查询全规则行，玩家和伙伴不会重复。
- 无新增、变化或窗口到期时保留当前统计版本。中断后已提交逐场事实可复用；未发布中间结果不会出现在页面。

页面使用分页API，没有全量JSON文件发布路径。证据读取与事实版本一致，所有计算均在本机数据库执行。
