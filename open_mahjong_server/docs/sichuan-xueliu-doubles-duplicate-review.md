# 血流双打复式接入现状

2026-10-11 已作为独立子规则 `sichuan/xueliu_doubles_duplicate` 实现。完整方案及与 SBR 血战的差异见[川麻 2V2 复式设计](sichuan-doubles-duplicate-design.md)。原随机单桌规则保持独立。

血流复式采用两桌对应手牌及牌墙相同，每队四人，分阶段对家换三张，队内不收付，和后继续行牌，两桌合算逐副差分，平分加副。沿用已有控猪、敌方必和、队友可选和及和后开杠限制。

2026-10-12 补齐 JJ 双重计分：两桌合并后的正副差分单副封顶 80，同时将 1–9、10–29、30–59、60 以上分别计为 1、2、3、4 IMP（0 为 0）。逐副换算后分别累计，当前按副分决定胜负。新建比赛规则快照为 `xueliu-duplicate-v3`，结算、牌谱、数据站同时保存和显示两套成绩。

2026-10-12 按用户提供的 JJ 图示及确认改为血流专用牌墙：每家 13 张起手、8 张固定墙，加 24 张公共墙。庄家第 14 张消耗本家固定墙；任意一家摸完第 8 张，立即把其他固定墙剩余牌按东、南、西、北整段拼到公共墙最前面，此后全部从公共墙头摸牌及补杠。普通血流复式与血流双打复式共用此布局。v2 起采用该牌墙布局；旧 v1 已保存比赛按原布局恢复。

手动构建、种子复现及密钥随机牌山均支持此布局。手动编辑提供四组 13+8 及公共 24 张；序列保存顺序为四组手牌与固定墙，再接公共墙。已有赛事血流牌山可绑定一组开闭室，副数沿用牌山定义；绑定与规则检查在事务内完成，不生成重复密钥。

复用平台的密钥及牌谱权限设施，新增双桌协调层；国标复式的取牌位置、空墙结束方式不用于川麻。比赛后台成对创建，普通创建入口只显示管理后台限制；开闭室固定交叉红蓝队，逐副等待，两桌成绩和完整牌谱有独立的披露时机。
