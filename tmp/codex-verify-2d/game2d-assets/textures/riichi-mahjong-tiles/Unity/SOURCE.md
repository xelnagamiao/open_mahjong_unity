These eight flower tile faces are copied from this repository's Unity client:

`open_mahjong_unity/Assets/Resources/image/CardFaceMaterial_xuefun/51.png` through `58.png`.

Mapping:

- Flower1-4: 春、夏、秋、冬
- Flower5-8: 梅、兰、竹、菊

The files are PNG derivatives made by trimming the unused outer background from
the original 220 x 366 Unity faces, then fitting the intact artwork proportionally
onto the same 300 x 400 visible face canvas used by the SVG tile set. This keeps
every in-game tile at the standard size without stretching or clipping the artwork.
