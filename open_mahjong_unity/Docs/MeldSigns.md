# 副露组合显示 sign

`combination_mask` 仍使用整数数组 `[sign, tileId, sign, tileId, ...]`。
这里只新增备用显示能力；当前上海敲麻以及其他规则不会生成 `101/102`，报敲、行牌、计分和牌谱动作格式不变。

| sign | 含义 | 显示约定 |
| --- | --- | --- |
| 0 | 普通明牌／手牌侧 | 按原有普通牌方向占一个横向槽位。 |
| 1 | 从牌河鸣入的来源牌 | 沿用原有横置约定；声明竖排副露的规则仍竖放。 |
| 2 | 暗面牌 | 沿用原有翻面、查看权限及结算暗杠显示约定。 |
| 3 | 加杠追加牌 | 仍关联本组的 sign=1 来源牌，保留原有各显示入口的加杠摆法。不是通用叠牌标记。 |
| 4 | 空位 | 不生成实体牌。 |
| **101** | **明面叠牌（备用）** | 叠在本组原始顺序中最近的 sign=0/1/2/3 牌上，继承其平面朝向，显示牌面。 |
| **102** | **暗面叠牌（备用）** | 归属及位置与 101 相同，显示牌背，查看行为沿用暗面牌。 |

连续 `101/102` 表示同一基础牌上的第 1、2……层，可以混用，不需要额外容量标记。
下一张 sign=0/1/2/3 开启新的归属和层数；sign=4 忽略。归属在 3D 倒序摆牌之前确定，不跨副露组。
叠牌不占新的横向槽位。3D 根据实际模型表面沿桌面法线逐层抬高，使用展示牌池，不占用每种牌四张的实体牌池；2D／结算在基础牌的同一列依次显示。

例如：

```text
[0, 11, 101, 12, 102, 13, 1, 21, 101, 22]
```

11 上面叠放明面 12 和暗面 13；横置的 21 上面叠放同样横置的明面 22。
若基础牌为加杠 sign=3，新叠牌跟随该加杠牌的实际显示位置。

孤立叠牌、非法牌值、尾部不完整的 pair 忽略；未知 sign 阻断后续叠牌的归属。牌值 0 表示未知牌，显示牌背。
`101/102` 是展示用附加牌，不参与从手牌删除基础副露牌；启用未来规则时应单独提供展示数据，避免把展示牌写入计分副露模型。
