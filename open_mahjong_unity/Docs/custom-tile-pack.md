# 自定义标准麻将牌面包

Unity 客户端和 Web 分享站接收相同的 ZIP。每张牌只需要一份原始 PNG，2D 手牌与 3D 牌面共用图片，分别配置位置、缩放。PNG 保持原始像素、比例与透明通道，导入时不重采样、不再次编码。

虹雀与拓展麻将固定使用各自标准包，可在客户端按包分别调整整体及单牌的 2D、3D 排版。

## 文件格式

```text
my-tiles.zip
├── 11.png … 19.png        # 万
├── 21.png … 29.png        # 筒
├── 31.png … 39.png        # 索
├── 41.png … 47.png        # 东南西北中白发
├── 51.png … 58.png        # 花牌
├── 59.png                # 通用花牌
├── 105.png 205.png 305.png # 赤五万 / 筒 / 索
├── 2.png                 # 纯白白板
└── tiles.cfg
```

只需要按代号命名的 PNG 和一个 UTF-8 `.cfg`，不需要 `manifest.json`、预览图或其他文件。可以缺牌，缺失图片回退官方牌面。仍兼容旧 `hand/`、`table/` 或「手牌牌面/」「3D牌面/」包；旧包明确提供的两份图继续分别使用，不会在导入时被覆盖。仅提供一侧的旧包会共用已有图片。没有配置的旧包使用位置 0%、缩放 100%。上传 PNG 完整等比居中，不裁切透明留白，不读取旧 PNG 排版元数据，也不叠加内置牌的历史位移或 86%/93% 缩放；整体、单牌以及 2D 背景基准点均以界面显示的参数为准。

## 排版配置

```ini
# x、y 为位置百分比；x 正值向右，y 正值向上。
# scale 为等比缩放百分比。位置范围 -100～100，缩放范围 25～200。
[2d]
x = 0
y = 0
scale = 100

[3d]
x = 0
y = 0
scale = 100

[2d.11]
y = 2 # 一万的手牌显示向上微调 2%
scale = 95

[3d.11]
x = -1
scale = 100
```

`[2d]` 和 `[3d]` 是整包默认值；`[2d.<代号>]`、`[3d.<代号>]` 是各牌的相对调整。支持 `#` 整行和行末注释。数值允许小数、可带 `%`；未填写的 x/y 为 0，scale 为 100。不允许重复配置段、重复参数、未知参数、无效牌号或越界数值，以免配置被静默误读。

整包和单牌参数组合为：`位置 = 整包位置 + 单牌位置 × 整包缩放`，`缩放 = 整包缩放 × 单牌缩放`（计算时百分比除以 100）。2D 再叠加当前背景独立保存的牌面基准点；背景图片本身不移动。内置包仍使用恢复后的旧版排版基准，雪枫万子以 `f5288fc1` 为依据。

配置值显示在相应滑条中。玩家修改优先于包内默认值，按牌面包、牌号和 2D/3D 保存；还原按钮回到该包配置的对应默认值。整体与单牌各有独立参数，不会跨包串用。缩放滑条中点为 100%，左右端分别为 25% 和 200%。

## 限制

| 内容 | 上限 |
|---|---|
| PNG 单边 | 4096 像素 |
| 每张 PNG | 4 MiB |
| ZIP 及解压后总大小 | 128 MiB |
| `.cfg` | 一个，不超过 64 KiB |

## 存储和兼容

桌面 / Android / iOS 新牌面包保存在 `persistentDataPath/TilePacks/library/custom-<id>.zip`。WebGL 保存在 IndexedDB `omu.unityAssets` 的 `tileBlobs`，键为 `tilepack/custom-<id>`。完整 ZIP 原样保存，包含配置；PlayerPrefs 只存目录、名称、选择和玩家的调整参数。

历史 `TilePacks/standard/`、`TilePacks/standard-table/` 和 IndexedDB `standardZip` 仍可读取。上传旧格式的玩家包仍可审核、下载并导入；站点不会自动重写上传文件。新格式需要本次更新后的客户端读取，分享站与客户端应在同次更新中切换。

Web 页面沿用原上传入口和说明区域，只需选择一个 ZIP。管理员预览从牌号 PNG 生成，无需上传单独的预览素材。
