# 2D 设定牌桌

入口：`/2d/demo`，也可从 2D 大厅的「设定牌桌」进入，无需登录。

示例直接复用正式对局的 `Game.vue`、`Game.css`、`MahjongScene` 与已保存的外观设置。牌面、手牌、中央计分区域、玩家信息、辅助按钮和设置面板均沿用原版；没有独立主题、头像、标题栏、抽屉或 DOM 手牌。

## 尺寸适配

- 横屏根据方向使用原桌面布局，牌桌在左、原设置区在右，不再因为手机宽度小于 900px 而改成上下排列。
- 横屏页面限制在一个可视高度内，设置区独立滚动；窄横屏仅缩小外边距和设置区宽度。
- 竖屏保留原版纵向布局与滚动方式。
- 监听窗口、屏幕方向、可视区域及画布容器尺寸变化，只重新计算画布尺寸与缩放，不重建牌局。
- 横屏外边距考虑设备安全区域。手机需允许系统自动旋转。

## 独立示例

`TableDemo.vue` 仅传递示例模式给原版对局组件。默认随机生成四家的手牌、1～3 组吃碰杠副露、牌河和补花，沿用 Unity 随机牌桌的展示内容；所有普通牌共用一副 136 张牌，8 张花牌各一张，随机分到四家。杠按一个副露组占用三张手牌位置，第四张为额外杠牌。吃牌始终从上家方向横置。

「国标番数表」下面依次显示「随机牌桌」和「退出牌桌」。随机会取消旧牌桌的跟牌计时并生成全新状态，保留外观与辅助设置；退出返回 2D 大厅。这两个按钮仅在设定牌桌显示，正常对局不显示。

「退出牌桌」使用红色按钮。游戏设置中的「牌面样式」可切换雪枫国标、Fluffy 立直白色与立直黑色，并显示牌面预览。原有白色/黑色选择保持兼容，新选择保存在当前浏览器；手牌、副露、牌河、补花、牌张设置、牌谱与结算使用同一资源选择逻辑。国标 PNG 原样复用已校准的 Unity 桌面素材（400 × 532），Pixi 和 DOM 均按素材约定的 0.93 显示区域等比适配，保留同花色的排版关系，避免原手牌素材留白叠加缩放造成图案过小；独立的 `table/` 资源路径避免旧图片缓存。花牌仍可独立选择图像或平面文字，特殊规则牌沿用原有素材。

本地数据通过正式快照结构显示，原牌面可直接出牌，三家按固定流程跟牌；不连接对局服务器、不计分结算。`/2d/demo?scenario=discard` 保留固定出牌样例，`/2d/demo?scenario=claim` 可检查原版吃碰按钮与副露。

原来额外制作的视觉页面、样式和辅助布局已归档到本机 `.om_workspace/2d-size-only/prior-design/`，不参与应用构建。

## 验证

`node scripts/test-game2d.mjs` 检查本地牌张守恒、原生快照、原生出牌与吃碰输入。浏览器检查桌面、手机横竖屏切换、设置区滚动及旋转前后牌局保留。浏览器尺寸模拟不能代替 iOS / Android 真机旋转验收。
