# 新加坡四人麻将：SPGG 2024 平台定型

规则键 `singapore/spgg2024`，配置版本 `spgg-2024-om1`。依据 [SPGG January 2024 原文](https://www.spgg.org.sg/web/content/114907/)（[NTU 校友会镜像](https://ntualumni.org.sg/wp-content/uploads/2025/02/mahjong-tournament-rules.pdf)）。这是一份赛事规则的平台实现，不宣称是新加坡全国统一规则。

## 平台补充约定

- 采用修订后的 **5 台封顶**。PDF 第 3 页的红色旧值 8、第 4 页的红色旧值 10 均不启用；旧支付表 6–10 台也不启用。4 台无花平胡保留专用支付档。
- 自动发牌，庄家 14 张、闲家 13 张；补花从牌尾逐张取，每家补完再轮下一家。始终保留 15 张。末张可和，放弃或不能和就流局，不再弃牌；末张花可以先触发八花和，但没有后续补牌。
- 起手加倍婚配仅指原始配牌已拥有的完整组合；补来的牌按途中档。婚配和整套奖励可分别计一次；暗杠用 2 分档，明杠/加杠用 1 分档，均由三家支付。
- 平胡自摸不限制等张；放铳须多面听且不能嵌张、边张。小三元含三元刻，小四喜含风刻；绿一色不叠计清/混一色。普通牌型允许按独立条目累加到封顶，特殊满贯固定 5 台。
- 大三元、大四喜在相关刻杠全部宣告后自动和。暗手中的对应牌型仍须完成和牌结构。八花自动和并转移第八花；八花自摸三家全付，抢花按来源玩家放铳支付。十三幺优先于其他和牌并三家全付。
- 包牌记录实际鸣牌形成的最近责任人；之后自摸或该责任人放铳才生效。依 A12，末 7/5 张“生张”只按出牌前当前牌河认定；已被吃碰取走、现仅存在于副露中的牌不算牌河中的熟张。末 7 张以内生张杠、末 5 张以内生张和由出牌者包付。
- 初始每人 400 分，任一玩家耗尽即结束。房间选择 1–4 圈，庄家和牌连庄；流局无杠连庄、有杠换庄。平台自动记录圈风，不设漏报风、错摸牌或实体操作罚则；非法动作由服务器拒绝。
- 只开放普通数据统计与牌谱，不开放番种累计统计和段位场。

## 条款和验收矩阵

| 原文范围 | 实现责任 | 必验分支 |
|---|---|---|
| A1–10、14 | lifecycle / 牌池 / 建房 | 148 张守恒、四人校验、13/14 张、死墙、连庄/换庄/末圈、400 分结束 |
| A11–13、27 | 状态机 / 包牌 | 末张普通牌/花/和/不和；生张 7/5 边界；各类包牌触发和解除 |
| A16–20、B23–26 | 纯规则计算 | 0/1/5 台边界、每个牌型、平胡等张、修订值、十三幺优先 |
| B21–22 | 即时支付 / 结算 | 起手/途中、对子/整套、各类杠、未成加杠、零和与幂等 |
| B24g、术语 | 补花 / 公共动作 | 连续补花、八花自然/抢花、无需完整手牌自动和、吃碰杠冲突 |
| 平台网络契约 | 公共收集器 / 路由 | 非法/跨规则/过期/重复动作、同时响应、超时/托管 |
| 平台持久化 | 通用记录和统计 | 小局净分、和牌/放铳/副露、最终名次、一次入账、无番种统计 |
| Unity / Web | 注册、表现与牌谱 | 建房、动物牌、操作提示、费用、结算、重连、回放、独立 Windows 构建 |

## 集成结构

服务端通过台湾状态机已有的可覆盖接口复用公共并发动作、补花广播、抢杠回滚、观战和重连；新加坡的计分、责任支付、自动和牌与对局生命周期独立实现。该基类与国标使用相同的操作帧、实体牌、座位和牌谱契约。

常规牌沿用原 ID，51–58 为花季；61 猫、62 鼠、63 鸡、64 蜈蚣，各一张。它们不进入普通面子求解器。手牌结构复用公共无万能牌求解器，不添加七对等原文未列的牌型。

每次即时支付写入 `singapore/payment` 牌谱事件；结算记录和牌净支付，局末累计包含即时支付。重连发送当前快照，不再次执行支付。每副结算和全场持久化分别设一次性保护。
