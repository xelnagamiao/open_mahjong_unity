# 番表资料来源

番表仅用于阅读，不修改实际对局计番。JSON 保留 `source`、`sourcePage`，青雀牌例另保留 `sourceExample`，用于逐条回查。界面不显示来源脚注。

| 规则 | 内容 | 定义来源 |
| --- | --- | --- |
| 国标麻将 | 82 条，13 个番数分类 | `other/rule/inclued_rule/新编MCR.pdf`，第 30–58 页的【定义】与【限制】 |
| 立直麻将 | 38 个役，1／2／3／6 番及役满 | Web 随附 `riichi-rulebook.pdf`（GGHK 香港麻将协会），第 23–26 页；立直说明另摘第 16–17 页 |
| 青雀 | 89 条，书载十类及权重 | Web 随附 `qingque-rulebook.pdf`（青雀 14.1），第 4–7 页；83 个牌例来自 `qingque-paili.pdf`（牌例 3.1） |
| 虹雀 | 基本规则 37 条 | Web 随附 `hongque-v1.6.pdf`，第 4–7 页；未混入第 9 页白牌变体番种 |
| 川麻血战 | 10 个番种及平和 0 番 | Web 随附 `sichuan-sbr.pdf`（四川麻将 SBR 竞赛规则，试行 2025 版），第 20–21 页 |

Web PDF 均在 `open_mahjong_web/client/public/rulebooks/`。国标 JSON 同步到 Web 的 `src/constants/guobiaoFanTable.json`，其余四套只在 Unity 展示。

整理只去掉 PDF 排版换行、统一标点和繁简字。国标定义内的三处牌面图片展开为牌名；立直的“见上文”改为摘录对应段落；青雀公式变量 `𝑞` 转为普通 `q`。原文的不计／不复计条件保留。青雀显示的是权重，不是固定相加的番数；偶然类的加算方式仍见完整规则书。

立直条目逐字摘录第 16 页第 3 项的条件列表、第 17 页第 11 项及第 23 页的“门清限定”；二杯口保留第 25 页定义的括号说明。三暗刻、四暗刻等简短定义也是该书原文，不另行扩写。

牌面示意与定义分开维护。青雀沿用牌例书中的首个例子，保留和牌张间隔、自摸／铳和与门风条件；其余示意按定义配置，虹雀用实际彩色牌资源，并经现有计番器验证每幅示意满足对应番种。

Unity 从当前规则进入番表，选择其他规则时切换分类和说明书地址。返回原规则时保留该房间子规则的说明书路径。川麻血流、双打等子规则继续使用各自说明入口，避免被血战到底的资料覆盖。

首页“背包”下方的“查看番数表”默认打开国标麻将，复用相同的阅读组件与五套资料；下拉切换规则后，完整说明书仍先显示外部跳转确认。
