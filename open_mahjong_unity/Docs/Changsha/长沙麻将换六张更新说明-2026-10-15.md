# 长沙麻将换六张更新说明

2026-10-15，待发布说明。

本次在长沙麻将中新增独立子规则"长沙麻将(换六张)"，采用固定的一整套玩法。主要增加开局换六张、每小局骰子禁小胡、报听、明牌、四喜、四张杠摇和闷杠，并配套调整计分、操作界面与牌谱。

文中的"一门"就是一种花色，"将"就是胡牌最后需要的对子，"保听"是杠或补张后仍保持规定的听牌，"鸟前分数"是扎鸟加倍之前的分数。

## 一、怎么创建房间

在创建房间页面选择"长沙麻将"，再从"子规则"下拉框选择"长沙麻将(换六张)"。原来的"长沙麻将(经典双鸟)"保留，并继续作为默认选项。

选中换六张后，页面显示这套玩法的说明，收起经典玩法中的可调规则项。切回经典双鸟时，原设置及其数值恢复。

| 项目 | 换六张玩法 |
| --- | --- |
| 用牌 | 108张数牌，万、筒、条各一至九 |
| 起手张数 | 庄家14张，闲家13张 |
| 换牌 | 每人六张，最多两种花色，当前启用一轮 |
| 选六张时间 | 10至60秒，逐秒可调，默认30秒 |
| 起手及中途即时收分 | 仅四喜 |
| 杠摇 | 一次公开四张 |
| 普通补张 | 一次补一张 |
| 终局扎鸟 | 两只鸟 |
| 小胡 | 每笔底分2分 |
| 大胡 | 一大8分，此后每多一大翻倍 |

开杠张数、鸟数、起手胡种类、底分、封顶和卡摸不作为这套玩法的自定义项目。房间名称、密码、局数、普通计时、观战等房间设置仍按原有用途使用。

## 二、开局先选六张，再掷骰交换

1. 发完牌后，四家各从自己的手牌里选六张，最多两种花色。
2. 点"确认换六张"提交。提交的六张牌只让本人知道，等待其他玩家选好。
3. 四家都提交后，播放两颗换牌骰子的动画，再按结果统一交换。
4. 动画结束后展示换来的手牌。
5. 换牌完成，先处理四喜，再由玩家选择报听、明牌，最后处理庄家天胡或继续打牌。

换牌骰子决定的是"拿谁的六张"：

| 两颗换牌骰子的点数和 | 拿牌来源 |
| --- | --- |
| 3、5、7、9、11 | 对家 |
| 2、6、10 | 下家 |
| 4、8、12 | 上家 |

例如掷出2和4，点数和为6，四家都拿各自下家的六张牌。选牌期间不提前显示这次换牌的骰子和方向。

如果交出的六张来自三种花色，仍完成交换，但该家判为相公，本局不能胡牌，包括四喜即时收分。

选牌使用独立时间，不扣正常出牌时间，也不额外叠加步时。超时由服务器自动选六张；重连后继续本轮剩余时间，不重新计满。

选牌提示、放大的确认按钮以及双骰显示都在自己手牌上方，牌河中间不再出现白色换牌对话框。

## 三、每一小局重新决定谁禁小胡

每小局发牌时，另外使用一组抓牌骰子，按本局庄家起算，指定一家禁止以普通小胡终局。连庄也重新确定。

| 两颗抓牌骰子的点数和 | 禁小胡的一家 |
| --- | --- |
| 5、9 | 庄家 |
| 2、6、10 | 庄家的下家 |
| 3、7、11 | 庄家的对家 |
| 4、8、12 | 庄家的上家 |

被指定的玩家显示"禁小胡"标记。该家不能用纯小胡接炮或自摸，但仍可听牌、选择海底、胡符合条件的大胡，也能收四喜分。

例如本局抓牌骰子为2和5，点数和为7，庄家的对家禁小胡。下一小局重新掷骰，按新的庄家位置重新确定；重连恢复本局结果。

抓牌骰子与后面决定交换方向的骰子分开。四喜的骰子鸟也另算，不使用这两组骰子的结果。

## 四、小胡、大胡和将牌

普通小胡需要四组面子加一个对子，对子须为二、五、八中的一种。面子可以是顺子、刻子或杠。

主要手牌大胡如下，符合的牌型可按规则叠加：

| 牌型 | 条件或计法 |
| --- | --- |
| 清一色 | 全部为同一种花色，并符合可胡结构，计一大 |
| 碰碰胡 | 四组面子全部为刻子或杠，计一大 |
| 全求人 | 四组面子全部已吃、碰、杠出来，手中单吊将，计一大 |
| 将将胡 | 全部为二、五、八，不要求普通面子结构，计一大 |
| 七小对 | 七个对子，计一大 |
| 豪华七小对 | 七对中有一组四张相同牌，计两大；两组为三大，三组为四大，替代普通七对 |
| 十三将 | 六种一九各一张，再加七种不同二五八及任意一张二五八；有将对一大，无将对两大 |
| 全幺九 | 全部为一、九，不要求普通面子结构，计两大 |

报听或符合手牌大胡条件时，可按相应规则放宽二五八将。只有天胡、地胡、海底、杠上花、杠上炮、抢杠等胡牌方式，仍须满足二五八将；明牌本身也不能让不合法的手牌成立。

天胡本身计一大，由庄家换完牌后选择。明牌、报听由玩家另行选择，不自动代选：天胡一大，加明牌一大、报听一大，共三大32分；再有清一色，就是四大64分。以上均未算鸟。

地胡按每位闲家自己的第一次实际取牌判断，包括第一次取牌前接炮及第一次取牌自摸。庄家再次摸牌，不会取消其他闲家尚未用掉的首摸资格；本家首摸后出牌或再次取牌，就不能再算首摸地胡。

## 五、报听、明牌和过胡

报听在开局符合条件时选择，计一大。报听后，将可以不是二五八，这也叫"假将"。原本普通小胡报听后胡牌，按一大8分；清一色加报听，按两大16分，鸟另算。报听后不能随意换掉原手牌，只能按规则进行保持听牌的杠摇，或杠摇锁手后的保听补张。

明牌计一大，手牌、之后摸进的牌和副露均公开。明牌与报听可以同时选择并累计。

声明也影响本人付款，但只增加本人这一笔：

| 情况 | 甲付款 | 另外两家各付 |
| --- | --- | --- |
| 甲报听，乙普通小胡自摸 | 8 | 2 |
| 甲同时报听、明牌，乙普通小胡自摸 | 16 | 2 |

表中均未算鸟。如果赢家自己报听或明牌，也把对应的大胡数计入自己的胡牌。

放弃接炮胡牌后，按以下限制处理：

- 普通过胡：同分或更低不能再接，直到本人完成出牌才解除。只摸牌不解除，升番可以再接。
- 报听过胡：本小局持续限制，摸切也不解除，升番才能再接。
- 明牌过胡：同完整手牌型、同分或更低不能再接；升番可接，实际听牌集合改变后恢复。

自摸不受这些过胡限制。多张杠牌过胡按完整分组后的鸟前分数比较，例如48分已过，之后32分仍不能接，64分可升番再接。

## 六、四喜即时收分

换牌后有四张相同牌，可报起手四喜；对局中摸齐四张，可报中途四喜。每一组分别收分，同一种牌本小局不重复收。

例如换完后同时有四张二万和四张七筒，两组分别结算，每组都按其他三家各付2分，再分别掷两颗骰子鸟。四喜收分后牌局继续，不改变庄家，也不叠加报听、明牌的大胡数。

海底摸到第四张也可以报中途四喜，先结这组四喜，再处理是否胡海底。

杠摇锁手后，如果原来有三张二筒，又摸到第四张二筒，仍可再收这一组中途四喜。收分不会解除锁手：之后只能选择合法的保听杠摇、保听补张，或打掉刚摸到的第四张。公开的四张杠牌作为开杠批次处理，不按普通入手牌重复报四喜。

## 七、杠摇、补张与锁手

杠摇一次公开四张，普通补张一次取一张。未听牌不能杠摇，但可以按合法动作补张。

杠摇掷两颗骰子，从墙尾按点数和定位，取连续两墩。起始墩不存在时才改用较小骰子；后续不足两墩时取实际可取的牌。取牌将耗尽牌墙时，保留最后所取墩的下层为海底。

杠摇后，原手和原有听牌对应的牌型锁住，不能再通过改变原手做出新的手牌大胡。原来不同听牌分别对应清一色、清碰等牌型的，仍保留这些区别。

之后摸到或公开开出的第四张，如果杠出后仍保持规定的听牌，可以继续杠摇，也可以选择补张一张；补张后继续锁手，单张补张不额外算作四张杠胡。

一次公开的四张牌按整批处理：先判断本家所有可胡牌，提供杠上开花选择；本家未胡时，再判断其他三家，可以一炮多响，也可以同一赢家胡其中多张。

没人胡时，先处理本家合法的续暗杠。选择续杠，只用对应的公开牌，其余牌进入牌河；不续杠时，其他玩家按杠摇优先、补张与碰同级、吃最后处理，同级按距开杠者最近优先，最多执行一次副露。

抢正式大明杠或小明杠，按抢杠胡加一大，由准备开杠者付款；抢单张补杠不额外升番。仅十三将可以抢暗杠。抢胡成立后，本次杠及后续取牌取消。

## 八、闷杠的操作顺序

闷杠在取下一张牌之前选择，并向其他三家声明。顺序固定为：

1. 先取一张，但暂时谁也看不到牌值。
2. 再开四张杠牌，四张全部公开。
3. 本家再查看先取的那一张。
4. 按整批本家优先的规则判断胡牌。

未明牌者的那一张仅本人可见。已经明牌的玩家也先私下查看，确认或超时后再公开给其他人。

支持补张前闷杠。例如手中有两个杠目标，先把其中一个做补张，在取补牌前用另一个目标声明闷杠。此时先隐藏的一张就是前一个补张要取的牌，随后再公开四张。

闷杠允许盲选。实际取到的那一张没有让本家听牌，杠仍成立，本家不能胡本批，四张公开牌继续给其他家判断，再按规定处理出牌。闷杠胡在对应杠上花或杠上炮的基础上额外加一大。

## 九、多张杠胡怎样算分

普通小胡每笔2分。大胡从一大8分起，每多一大翻倍：

| 大胡数 | 一大 | 两大 | 三大 | 四大 | 五大 |
| --- | --- | --- | --- | --- | --- |
| 鸟前分数 | 8 | 16 | 32 | 64 | 128 |

自摸由其他三家各付，接炮由放炮者付。下面的分数均为加鸟之前的一笔付款。

同一个赢家胡多张杠牌时，先按完整手牌牌型组合分组。同一组的手牌大胡只算一次，每张能胡的杠牌再各加一大；不同组分别算完再相加。

| 可胡的杠牌 | 计算 | 鸟前每笔付款 |
| --- | --- | --- |
| 三张都为清一色 | 清一色1大，加3次杠胡，共4大 | 64 |
| 一张清一色，一张清碰 | 清一色杠胡2大16分，加清一色碰碰胡杠胡3大32分 | 48 |
| 两张清一色，一张清碰 | 清一色组3大32分，加清碰组3大32分 | 64 |

清碰指清一色加碰碰胡。同样都是几大，如果完整牌型组合不同，仍分开计算。

杠上开花和杠上炮采用同样的分组算法。一张清一色加一张清碰，本家杠上开花时其他三家各付48分；杠上炮时由开杠者付48分，再分别计算鸟和相关声明。

## 十、两只鸟怎么加倍

一次终局胡牌或同一次开杠的整批胡牌，只扎一次两只鸟。多名赢家、多张胡牌和多个牌型组共用这批鸟。

只有一位赢家，以赢家起算；有多位赢家，以放炮者起算，开杠多响则以开杠者起算。

| 鸟牌数字 | 落在起算玩家的哪个位置 |
| --- | --- |
| 1、5、9 | 本人 |
| 2、6 | 下家 |
| 3、7 | 对家 |
| 4、8 | 上家 |

逐笔付款判断：鸟落在赢家或这一笔的付款者身上就算命中，每中一鸟乘2，两只都中乘4。例如鸟前48分，中一鸟付96分，中两鸟付192分。

牌墙只剩一张鸟牌时，这一张重复计算两次；海底胡使用海底牌重复计算两次。四喜用两颗骰子分别作为鸟，按各自点数定位，不把两骰相加。

## 十一、海底和下一庄

只剩最后一张牌时，从本应摸牌的人开始，听牌玩家依次选择是否要海底。要到后能胡可以自摸；不能胡或选择过，就打出海底牌，其他三家只能胡或过。

下一庄按实际赢家人数确定：

- 一位赢家，由赢家坐庄。
- 两位或三位赢家，由放炮者坐庄；开杠多响则由开杠者坐庄。

同一个赢家胡多张牌或多个牌型组，仍只算一位赢家。四喜即时收分不改变庄家。

## 十二、界面与记录调整

- 换牌提示、放大的确认按钮和骰子在自己手牌上方，选中牌保留高亮。
- 吃、碰、杠、胡、过、报听、明牌和查看确认，使用原有手牌上方操作栏；多种吃法展开实际候选牌组。
- 修复点击鸣牌后请求未进入正确处理入口、操作无响应的问题。
- 四张公开杠牌按统一尺寸展示，避免牌面花纹超出槽位。
- 重连恢复本轮提交、剩余时间、声明、禁小胡标记和当前动作。
- 对局记录保留换牌轮次、骰子、四喜即时分、完整牌型组、各家付款和鸟倍数。
- 修复四喜后历史分数漏记或重复计分，多响回放展示全部赢家。

## 十三、第二轮换牌预留

流程已保留先换一轮、按条件再换一轮的能力，最多两轮。第二轮使用第一轮换完后的手牌，重新选六张、收齐四家提交，再统一交换；每轮独立计时，重连与牌谱保留轮次。最终换牌结束后，才处理四喜、声明和天胡。

第二轮的触发条件、骰子及方向确定办法仍待补充。当前正常对局只启用一轮，房间里没有自由设置换牌次数的选项。

## 发布范围与当前状态

本次功能限于长沙麻将及"长沙麻将(换六张)"。经典双鸟保留原入口、默认选择与设置；其他麻将玩法不增加换六张行为。共用的建房、网络、手牌点击、牌谱和计分展示入口，只接入长沙专用分支。

代码在独立工作分支中准备，本地主线未改动，其他麻将玩法的规则文件未修改。

已通过180项长沙回归、127项共享房间回归、1494项客户端检查，并完成当前客户端的Unity编译。建房设置、手牌上方操作区、双骰、本机四小局联网及本地牌谱回放已有验收记录；新位置的确认按钮已通过本机联网提交。

四小局实测均为流局，复杂胡牌和闷杠目前由自动回归覆盖，独立观战客户端、真实断网恢复及其他窗口尺寸尚未原生实测。

这份说明随换六张子规则提交审阅，功能尚未合并或部署。
