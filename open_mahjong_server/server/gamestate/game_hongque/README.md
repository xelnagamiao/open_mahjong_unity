# 虹雀² v1.6 原型

这是一个独立、纯内存的 `hongque` gamestate。它不调用数据库统计接口，也不创建或保存牌谱。

## 启动

1. Unity 建房界面选择“虹雀²（原型）”。
2. 邀请四名玩家，或用普通机器人补满四席。
3. 全员准备后开始游戏。

客户端会显示运行时生成的 2D 原型桌面，牌面直接加载
`Assets/Resources/image/HQv3.1/{牌码}.png`。

## 牌码与规则范围

- `AX1..GX9`：红、橙、黄、绿、青、蓝、紫七种纯色。
- `AY1..GY9`：红橙、橙黄、黄绿、绿青、青蓝、蓝紫、紫红七种半色。
- 服务端内部将花色映射为模 14 环，数字保持 1..9。
- 已实现：发牌、摸牌、弃牌、补牌（每人每局至多两次）、动态枚举吃/碰/虹、亮牌优先级、明牌加杠、摸和/捉和、流局与连局。
- 彩虹按规则 6.2.1 作为独立牌组处理：牌组覆盖七种基础颜色即可。
- 当前结算仅计算底分（3 分、长牌组加底、门清加 2 底）；v1.6 完整番种表留待原型验证后接入。
- 白牌、黑牌、空牌变体不在本原型中。
